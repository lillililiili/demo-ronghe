# dongying-vue —— 东营无人机融合感知平台 Demo（Vue 3 版）

原纯静态 demo（`../dongying-demo/`，**一个字未动**）的 Vue 3 迁移工程。
路线：**混合起步，逐页 Vue 化** —— Vue 外壳 + legacy 页面逐字节保留起步，
之后按页转成真 Vue 组件，每页以「与 legacy 并排 DOM 指纹一致」为验收门槛。

## 运行

在本目录 `dongying-vue/` 下：

```bash
npm install
npm run dev        # http://localhost:5173（hash 路由与旧版地址完全兼容）
npm run build      # dist/ 约 5MB，瓦片不进产物
npm run preview    # 生产产物预览（瓦片中间件同样生效）
```

“我的工作台”前台模块已移除，包括菜单、页面组件、专用样式和前台接口适配。默认首页、登录后的默认落点与“首页”链接改为融合感知；旧 `#/workbench` 地址重定向到 `#/situation`。后端接口、历史记录及其他页面共用的核实/通知能力保留。

运维管理、系统管理的菜单入口已移至同级 `houtaiguanli` 后台，业务前台不再展示这两组菜单。六个旧管理地址保留迁移提示，不自动跨系统跳转，也不再加载旧管理页面组件。

业务前台侧栏各模块默认全部展开，可独立收起；切换页面时展开目标模块，不收起其他模块。飞行计划“计划信息”标题旁不再显示“查看关联风险”按钮，风险仍可通过“全部风险事件”页签及计划风险记录查看。

业务数据和登录会话调用 Spring Boot `/api/v1`。平台唯一后端位于同级后台仓库 `../../houtaiguanli/server`，在该目录以 `local` profile 启动；Vite 默认将 `/api` 代理到 `127.0.0.1:8081`。本仓库不再维护 Java 后端。部署到不同 API 根地址时设置 `APP_PUBLIC_API_BASE_URL`，值可为 `/api` 或已包含 `/v1` 的完整地址。

旧版对照：项目根 `node serve.js` → http://localhost:8899。两个同时开、同 hash 并排比对，
是所有验收的基本姿势。

## 空域管理模拟观测

页签按“空域列表 → 空域监测”排列，进入页面默认显示空域列表；详情中的“查看范围内列表 / 风险”仍切换至空域监测。

本页日常空域清单按已核对的 ID 排除“重启自检临时管制区（自检-临管-24153）”“测试临时管制区（临管-2026-001）”“禁止演示空域（空域-001）”三条测试记录，列表数量及本页地图同步排除。此处理仅发生在业务前台页面，服务端空域、六个历史版本及已有评估/研判引用保留，其他空域不按名称或未生效状态批量隐藏。

详情栏默认隐藏，不显示空白占位；点击记录或地图对象后才展开右侧详情。未选中对象时，地图占用左侧列表之外的全部宽度，列表宽度保持不变。

已有业务风险记录在右栏使用与飞行计划“风险详情与处理”一致的信息结构和视觉组件：风险概览、等级/状态/高度、光电追踪与视频、事件信息、风险依据、核验历史，以及“通知与回执”页签。人工核验复用共享弹窗，通知调用同一风险交接接口；依据服务端动作与当前状态开放操作，保存后回读详情并同步列表和地图。已提交的通知不重复提交，超时保留幂等键并回读核对。纯模拟观测及尚未关联风险的监测目标保持只读，不生成核验、通知或设备任务。 空域风险和飞行计划风险（含气象）在待核验阶段展示“人工核验”及暂不可用的“通知上级”，明确先核验后通知；核验通过后开放通知，已排除或已提交通知保留历史。光电追踪在活动任务期间自动回读回执，仅成功回执后展示模拟视频，关闭详情时停止轮询。

“空域监测”参照飞行计划的三栏布局：左侧紧凑记录卡片、中间地图、右侧详情，各栏独立滚动。顶部常驻风险类型、等级和明确标注的“筛选”入口；重点区域（接口模式为监测窗口）、范围、状态和时间收纳到默认折叠的“更多筛选”，展开浮层不压缩工作区。筛选即时生效，收起后保留已选条件标签、数量及逐项移除/清空入口。距离、高度和位置口径收纳在可展开的“监测说明”中；缺少有效位置的数量单独以警示色显示，权限、读取失败与重试提示仍直接显示。

`#/airspace` → “空域监测”可切换“模拟演示 / 接口监测数据”。开发服务默认显示模拟演示，生产构建默认读取接口；接口失败不回退模拟。模拟场景独立存于 `src/pages/airspace/airspaceMonitorDemo.js`，不写入目标、风险、设备或通知记录。旧 `public/assets/js/mock.js` 当前已不存在，不作为本模块的数据入口。

点击地图空域或空域列表记录只高亮并查看详情，不自动启用范围筛选。点击详情“查看范围内列表 / 风险”，或在“更多筛选”中选择所选空域，才进入所选空域范围；手动启用后范围跟随当前所选空域。移除范围标签后，继续点选或刷新空域不会重新启用筛选；关闭空域详情时清除该范围。

空域监测与风险记录共用一张风险列表、一组范围/类型/等级/状态/时间筛选和一套分页；“空域列表”入口保留。监测目标通过接口明确给出的 `risk_summary.risk_id` 与风险记录关联，同一风险只占一条；不同风险编号保留各自记录。模拟观测保留模拟标识、距离、高度、数量和运动趋势，未关联风险的真实观测标为“未记录风险”，不虚构核验状态。所选空域与区县范围同时作用于两路数据；时间按风险发生时间或无风险观测的最近发现时间进行 `[开始, 结束)` 筛选。重点区域仅限制模拟场景，监测窗口仅限制近期目标读取，不截断历史风险。地图位置与合并后的筛选结果同步，图层开关独立控制近期位置和风险发生位置。工作区占用页面剩余高度，记录列表与详情各自滚动，地图持续可见；低高度窗口保留页面最右侧的整体滚动。分页固定在左栏底部。点击左侧记录或地图目标时联动中间地图和右侧详情；详细距离、高度、数量和运动趋势集中显示在右栏。定位仅调整地图与选中状态，关闭详情保留筛选、分页和列表滚动位置；缺少位置仍可看详情，定位按钮禁用，不跳转飞行计划风险。读取失败和无权限分别提示，保留另一数据源已读内容。此处布局与选择操作不改变业务风险记录。

无人机机巢周边、重点设施、航线附近、空域边界各有两组目标，七帧样例每十秒循环，可暂停及逐帧查看。机巢指无人机自动起降设施，样例关注其起降点周边的空中目标，不代表机巢设备健康或起飞许可。距离分别为到机巢起降点、设施中心、航线中心线、空域边界的水平距离；高度为海拔高度（AMSL），不与离地高度换算；鸟群按只、气球按个。空域样例展示界外、边界上、界内及跨越平面边界的过程，不推导违规结论，也不修改上级下发的空域台账。运动趋势、水平速度、垂直速度及数量变化均对应前后两个观测点。地图、记录列表及所选目标轨迹使用同一帧数据，场景位置与等级明确标记为模拟。鼠标停在模拟参考点、名称、航线或空域内部及边界时，显示名称、类型和距离参照说明；合法航线也支持悬停查看名称。离开、拖动、缩放、切换图层或筛选后清除提示，提示不拦截地图操作。

地图沿用飞行计划风险事件的鸟群图标、圆点、热区与紫色轨迹绘制。点击目标、左侧记录或详情“定位”查看距离连线与轨迹；图例中可切换目标和热区图层，热区仅表达目标组位置，不代表个体数量。区县与手动启用的所选空域边界限制显示范围；要看全部样例，选择“全市 / 全部重点区域”并移除范围筛选。

飞行计划的设备自动检查会将附近异常设备标在计划地图上，沿用检查结果的 30 秒刷新节奏，位置从设备台账读取。当前异常设备使用闪红光的设备图标，历史告警使用不闪烁的黄色图标；鼠标悬停或键盘聚焦时显示设备信息。地图卡片与下方设备记录右侧统一使用“通知设备异常”，需要 `handoff:create` 权限，当前异常或有未关闭告警时显示。点击向后台生成运维待办，不再跳转旧设备监测页；只含已关闭历史告警的设备保留信息、不显示通知按钮。位置不可用时仍可从列表通知。

运维待办接收端位于 `houtaiguanli/server`，管理端“运维管理 → 设备实时监测 → 运维待办”可查看及记录处理结果。前台和管理端必须连接同一新版后台与数据库，各自登录：本前台 Vite 与管理端默认均连接后台 8081；如需其他开发地址，在此前台目录通过 `APP_API_PROXY_TARGET` 或既有公共 API 地址配置统一连接。不能只把通知请求转发到另一套登录库。同一计划/设备有未处理待办时返回原待办；超时重试沿用提交键。处理结果不自动改变设备故障或恢复核验状态。2026-09-15 已启动后台开发服务并应用设备运维待办迁移；此处不代表真实设备处理结果已经验收。完整接口见后台仓库 `docs/设备异常通知与运维待办.md`。

飞行计划与全部风险事件现采用“左侧记录列表—中间地图—右侧详情”布局。列表以卡片突出状态、时段和摘要，排序及分页仍调用服务端。风险的通知与回执放在右侧页签中，左侧始终保留风险列表；待核验与待通知分别显示对应操作，历史记录继续保留。窄屏将地图和详情分行。

“全部风险事件”列表仅展示异物和气象风险（`SPACE_OBJECT/FOREIGN_OBJECT/WEATHER`），不混入空域风险、飞行作业风险。列表、分页总数、状态/等级统计和 CSV 导出均带 `risk_types` 范围参数；类型筛选也限于本页范围。范围外记录的旧详情链接会显示提示，不在这里打开其详情。本次不删除风险记录，也不调整计划详情及其他页面的风险查询。此修改需要运行包含 `risk_types` 支持的后端版本；未执行构建或运行验收。

计划详情的“查看关联风险”通过 `#/flights?tab=events&plan=<计划 ID>` 筛选；点击具体风险额外携带 `risk=<风险 ID>`。风险详情通过 `#/flights?plan=<计划 ID>` 返回关联计划，目标不在列表当前页时仍按 ID 读取详情。风险列表会提示计划筛选范围，可点击“查看全部”清除；已有设备详情跳转与气象范围展示继续保留。

## 与 dongying-demo 的同步纪律（多会话并行是常态）

demo 侧随时有并行会话在改。**同步流程**：

```bash
bash tools/parity-diff.sh            # 任何 DIFF 都表示 legacy 副本落后
```

1. **未转换页面 + 共享 JS + img**：直接重拷（`cp`），零风险。
   **CSS** 在 `src/assets/css/`，不与母本逐字节同步；上游样式 diff 重放到对应切片。
   大屏已 Vue 化，需按差异迁移。
2. **已转换页面**：`git diff -- dongying-demo/assets/js/pages/<页>.js` 看上游改了什么，
   把 diff 重放进对应 `src/pages/*Page.vue`，然后与新版 legacy 并排指纹比对。
3. **app.js**：属外壳，diff 重放进 layout 组件（HeaderBar/Breadcrumb/navModel/PageHost）。
4. **index.html**（demo 侧）：新增 script 标签 → 本工程 index.html 同步加；
   新增顶栏控件 → HeaderBar.vue。

## 页面转换配方（逐页 Vue 化的固定打法）

1. 读 legacy `pages/<页>.js` **当前版本**（不要凭旧读缓存——上游在动）。
2. 模块级状态 → SFC 非 setup 的 `<script>` 块（跨导航保持，legacy 约定）；
   若 legacy mount 本就重置全部状态（如 commission），直接放 setup。
3. render() 外骨架 → template（UPanel/UKpis；面板体沿用 U.* 字符串走 bodyHtml，
   **禁 v-html 包裹节点**——元素数必须与 legacy 逐一对应）。
4. mount() → onMounted（U.on 委托绑在组件根上，:key 重挂时随节点销毁）；
   destroy() → onUnmounted（usePageChrome 先注册，保证 disposeAll → 页面清理 → closeModal 次序）。
5. **模块加载期副作用（U.regParams / 数据注入）一律留在 legacy script，SFC 不重复。**
6. 验收：双服务并排，`元素数 + 全文哈希`（textContent 去空白）一致才准登记进 registry.js。
   含 rAF 绘制内容的页（地图比例尺/点型计数）先把这些片段正则中和再比。
   ⚠ 测量前确认视口可见（隐藏标签 rAF 暂停、定时器节流，量出来的是环境不是页面）。

## 地图与部署

普通页面与数据大屏的顶栏不再展示天气，也不再启动天气刷新定时器。

原 1.5GB / 32 万张离线瓦片仅保留作历史回滚数据，Vite 不再转发、构建不再复制，
运行时不会产生 `/assets/tiles/**` 请求。`tools/tilecheck.cjs` 仅用于人工审计旧瓦片包。

## 组件库（Naive UI，2026-08-31 引入）

列表筛选栏的操作按钮使用 `.toolbar-actions` 成组靠右，换行后保持右对齐。
设备调测页的设备树支持点击区域标题或使用 Enter / 空格键展开、折叠；各区域独立保留本次页面内的折叠状态，重新进入页面时恢复展开。
表格正文默认 16px、紧凑表格 15px、辅助文字 13px，由 `tokens.css` 的表格字号变量统一维护；长表格在局部容器内滚动。
分页器统一使用 `.pager` 收在表格右下方，每页条数下拉框宽 104px；窄容器内可换行，禁止拉伸占满整行。

交互件全套替换（P0–P4a 完成 + P4b 样板），展示串（tag/kv/sect 等 ~280 处大屏视觉签名）不替换：

- **P0 主题**：`src/ui/theme.js` 运行时 getComputedStyle 读 `src/assets/css/tokens.css`
  生成 themeOverrides（token 文件保持唯一真源，勿手抄色值）；App.vue 包 n-config-provider。
- **P1 toast 96 处**：`src/ui/nv.js` 的 `toast()` → message.success/error/info。
- **P2 分页 4 页**（Alarms/Evidence/Devices/Legality）→ n-pagination 受控；
  其余 4 页列表区命令式 innerHTML，pager 保留（P5 项）。
- **P3**：situation techDrawer → n-drawer；Users/Archive 模板层 tabs → n-tabs。
- **P4a 弹窗桥接**：`src/ui/modal.js` 的 `openModal/closeModal` 与 U.modal 同签名同契约，
  全部 U.modal 调用点换壳 Naive；同一事件连开两次走微任务合并（防孤儿容器）。
