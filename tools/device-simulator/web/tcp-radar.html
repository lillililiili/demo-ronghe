在后台“设备管理”找到“模拟 独立 TCP 雷达”，查看原生协议状态与航迹。已发送帧数表示模拟器发出，不代表平台全部接收。

本次演示提供什么

数据登录、心跳应答、寄存器读取、RTK 上报，以及每秒一帧的模拟无人机航迹。后台通过现有 TCP 适配器接收并保存原始数据。

雷达相对站址的高度不作为离地高度。该协议未提供明确的健康与告警清除证据，因此在线不代表设备处置单已恢复。此入口暂用于协议接入与原始航迹验证，模拟航迹不会混入真实目标通道。
