# 当前批次计划匹配

用户确认：只让当前批次参与匹配，旧批次保留历史。

## 行为与修正

后端 `SimulationPlanBatchService.activate` 按组织、区域锁定并原子切换批次；`SimulationPlanBatchRepository.eligibleSql` 约束规则引擎的计划候选。批次关系独立持久化，不改旧计划、研判、轨迹或风险；同批次请求幂等，清单改变或旧批次重放返回 409。来源、权限、时间、身份与走廊条件仍生效。

本轮补齐 `FullChain.activate_plan_batch` 的历史清单兼容：只纳入保存过 replay 报送依据的历史计划，并完整分页核对当前平台可见记录；排除旧版种子清单及另一数据库编号。历史读取失败或不完整时不调用激活接口，不把部分历史名单当成完整结果。当前名单仍由后端逐项校验。
