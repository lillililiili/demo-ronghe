# 联调日志模板

2026-09-09。每一路复制一张表填写。本机模拟与现场射频必须分开勾，禁止把本机成功抄成现场完成。

控制回执**不得**作为融合 inbox 领取成功的证据。

## 填写约定

- **环境**：只选一档。`local 模拟` = 种子/回放/`CM4-LOCAL`。`配置 live` = 填了真实地址但未做射频验收。`现场射频` = 客户现场、有发射或真实探测责任人签字。
- **报文**：原样粘贴（MQTT JSON 或 TCP 十六进制）。不要重新 `json.dumps`、不要改冻结 NDJSON。
- **结论**：通过 / 阻塞 / 遗留。阻塞要写错误码原文。
- **遗留编号**：自编 `L-日期-序号`，收口时在本表改结论。
