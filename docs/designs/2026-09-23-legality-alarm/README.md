# 页面设计交付包

打开 `index.html`，或使用本机预览 `http://127.0.0.1:8933/index.html`。

## 包含什么

- **告警页面、合法性判定**：沿用原页面的导航、统计、列表、地图和图标，调整当前详情及核对入口；支持9种状态切换。
- **详细规则**：44项情况可搜索、按主要入口筛选、展开查看前提／系统动作／人工操作／后续确认／能力边界。
- **操作流程**：8条常用流程，可直接切换到对应设计状态。
- `页面设计与处理规则.md` / `rules.html`：完整页面设计、规则、操作流程、异常处理、实施依赖和验收清单。
- `44项场景处理清单.md`：可独立阅读的逐项处理清单。
- `verification/`：页面对照及设计验收截图。

本包全部是设计评审资料。业务接口不写入、原Excel不覆盖、生产前后端源码未因本次设计交付而修改。复核记录只存在当前评审页面的内存中，刷新重置。反制和通知按钮只说明设计去向与条件，不发送命令或真实消息。

原页面对照使用9月20日留存DOM、CSS和地图快照；本轮结合当前源码及用户截图校正核实位置筛选、关联入口和删除面板。不能将该底稿称为9月23日实时截图。其列表、统计和地图只供布局参照，状态切换不代表这些历史样例全部参与重新统计。桌面保持原分栏；窄评审窗口将告警列表、地图及详情纵向排列，点击“定位详情”可快速查看。

## 本轮验证（2026-09-23）

浏览器实际操作验证：

1. 告警中点击核对，原地展开表单；空说明被阻止。
2. 填写说明并保存后，切换合法性页看到同一复核记录，未伪造风险解除。
3. 无告警状态在合法性页显示本页核对按钮，并能展开对应缺口表单。
4. 可靠偏航不显示强制核对按钮。
5. 观测过期时手动反制入口返回明确阻断原因。
6. 无复核权限时没有核对按钮；已解除场景无新的手动反制入口。
7. 短信已送达与电话失败独立显示。
8. 关联同步失败状态说明依赖该结论的新通知与反制不能推进。
9. 清单初始化显示44/44项，搜索“黑飞”命中包含该条件的3项；8张流程卡可见。
10. 1440×1100桌面布局与原页面底稿对照；首轮发现详情原始样例与状态不一致，随后同步修改选中记录依据和状态、折叠重复依据并复查。窄窗口详情压缩问题已改为纵向排列并截图验证。图标与底稿为同一资产，未重画替换。

文件验证：JavaScript语法检查通过；本地HTML引用资源完整；没有远端HTML资源依赖；源Excel共44条读取成功；本目录新增源码与文档执行空白检查。

边界：未做生产API、真实短信／电话／设备／视频或自动移送验收；未运行生产构建、迁移回归和扫描，因为本轮仅交付独立设计文件。浏览器曾记录一条MutationObserver错误，本包源码不存在该调用，来源未定位，故不声称浏览器控制台零错误；上述关键交互已实际通过。

## 实施前必须完成

当前后端的研判复核和事件核实仍分开，复核不会自动推进告警核实状态。须先完成后端结论采纳、精确关联、异常恢复和动作校验，再取消对同一事实的重复人工核实，不能只移除前端按钮。具体见完整规则第10节。
