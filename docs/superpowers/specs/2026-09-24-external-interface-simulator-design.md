# 外部接口模拟页设计

用户已确认：输入侧飞行计划、天气预报；输出侧风险通知上级、处罚移送，支持成功、失败、超时并接通本地联调。沿用已有模拟器样式与独立服务，新增 `/external.html`，顶部两个页面入口。

## 交互与数据流

左侧四类接口，中间样本表单/收到的通知，右侧请求、回执及平台结果。独立连接设置复用平台登录，不依赖 MQTT 连接。输入消息携带稳定 message_id，重复相同内容返回原结果，不同内容冲突；计划引用现有可见模拟航线，不补真实授权，天气绑定可见模拟计划并显示有效时段。来源始终 mock。

输出侧由用户选择一个实际模拟风险或无人机事件，启用最长20分钟的本地接收绑定。现有通知提交仍经过原核实、动作权限和渠道配置检查；渠道将真实待发送内容持久化到本地外部模拟收件箱。页面拉取收件箱代表模拟外部系统接收，按该条消息返回送达、签收、失败或超时。不是从页面直接创建成功交接。签收不自动解除风险或办结处罚。

## 服务端边界

`/api/v1/local-interface-simulator` 仅 local/test 且非 prod/production，可用接口操作权限；再次按原对象读取权限和范围验证。模拟消息、接收绑定单独持久化，原交接投递事实由 handoff 应用服务按消息关联更新。历史成功结果不得回退；重复同回执幂等，不同回执需要当前版本并遵守状态迁移。停用接收不删除历史，旧记录不能凭当前配置改成成功。

天气返回沿用现有 Forecast DTO，仅为外部模拟器明确绑定的计划提供最新持久化样本，旧模拟预报与真实配置保持原读法。计划通过受控后端接入应用服务新增，不再由页面直接写库。无外部生产协议时只声明本地联调契约，不宣称已接入真实第三方。

## 验证

后端测试覆盖输入校验、来源/权限隔离、重复输入、消息关联、重复/冲突回执、成功不可回退、有效期和重启持久化；迁移与SQL在隔离PostgreSQL验证。页面测试载入样本、推送、回读、接收及回执、失败/超时、刷新、重新登录，保存真实API证据。五组MQTT场景及旧历史保留。
