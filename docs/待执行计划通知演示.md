# 待执行计划通知演示

2026-09-11：本地开发示例新增五条计划（计划-0911-101 至 105），其中 101、102、103 分别配有模拟鸟群、气球、鸟群风险。

入口：飞行计划 → 待执行 → 选择上述计划 → 本航线风险 → 通知上级。使用标准风险查询和交接提交接口，提交后风险进入已通知；模拟渠道的送达与回执状态独立保存。

飞行计划页优先显示航线名称、时段、风险类型与状态，删除计划编号筛选；编号仍保留在 API、数据关联与导出中。风险详情增加光电追踪区域，按关联目标读取任务并通过已有接口人工补发，缺目标、权限不足或风险已排除时禁用发起按钮。跟踪任务处于进行中时才显示由浏览器生成的模拟视频；任务结束或正在结束时关闭画面。操作者可对进行中的任务点“结束追踪”，接口回执决定最终状态。模拟视频带永久模拟标记，可播放、暂停及全屏，不代表真实现场画面。切换风险或离开页面会释放视频流和动画。

本地 `local` 环境另登记一台“本地模拟视频光电”（`LOCAL-RISK-VIDEO-EO-001`），只服务阶段三演示机构和区域。它每秒发送协议 C 心跳，并对开始、结束跟踪返回模拟回执，使关联的鸟群风险可完整演示“发起追踪 → 模拟画面 → 结束追踪”。该设备和 `LocalRiskVideoEoSimulator` 都仅限 local 的开发种子；接入真实光电及真实视频流后删除这两项，页面仍应等真实设备回执后展示真实画面。

`LocalPendingPlanDemoSeeder` 仅在非 production 的 local/test 环境且 `app.dev-seed.enabled=true` 时运行。航线与计划使用执行状态样例的独立机构、区域。风险通过标准可信事实入库服务创建，标记 mock，原因和核验说明明确为模拟夹具，不代表真实评估或人工核验。

重启时仅重新定位五条专属计划的未来窗口（已取消计划不恢复）；风险、核验历史与通知记录不重置、不重复创建。风险沿用首次生成时刻，超过页面近七天筛选窗口后不会显示；此样例用于当前演示，不制造新的观测事实。

验证：计划数量及未来窗口、三条空中异物风险和核验记录、标准接口提交通知、重复播种后状态及通知记录保留；同时在本地 PostgreSQL 和浏览器核对实际入口。
