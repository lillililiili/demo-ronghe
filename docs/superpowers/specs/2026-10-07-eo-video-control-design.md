# 模拟器独立视频开关

用户于 2026-10-07 确认：在“开始模拟”旁增加“开启视频推流 / 停止视频推流”，允许运行中切换；没有当前跟踪任务时等待任务，停止视频保留目标上报与跟踪。业务前台只播放，不承载模拟器控制。

- 新增本机同源 POST /api/video，enabled 为严格布尔值；可携带既有视频配置字段。启动/配置校验当前登录、FFmpeg、本机来源、回环 RTSP 与已有凭据规则。关闭不因会话失效被阻断。
- HTTP 线程只发布经过验证的配置；MQTT 所在线程同步配置、清理编码器和注销视频登记，避免并发清理及重启竞争。
- 切换不删除 active 跟踪任务、不加入 retired、不发停止设备指令。开启后再次核对平台当前 OPEN 任务，复用任务登记；重复开启不新建编码器。
- 主按钮旁显示关闭、等待模拟、等待跟踪、切换中、正在推流或失败原因。媒体进程运行不等于前台可播放。设置单独可达，推流启用时禁止修改源/凭据。
- 凭据只驻进程内存，状态、日志、导出和场景文件均不包含密码。部署仍保持 dev-seed=false，不扩大 live 能力。
- 验收：单元/HTTP 回归；真实浏览器点击开→关→开，核对同任务持续上报、编码器退出与重新启动、前台视频时间推进。未完成媒体或浏览器链路时如实报告。
