## 写作时做过的判断

1. **正文从三类改成四类。** 上一版把"起降点尚未接入"这种归在"尚未接入"里；现在它是"起降点未知"，性质变了——**"能力没接进来"要找对接方，"这条记录缺事实"要找数据**。混在一类里会把责任方指错。
2. **"尚未接入"这个词已经不在界面上，正文因此不再用它作分类名**，改用页面上真正出现的措辞。**文档里出现界面上没有的词，验收方会去找、找不到，然后怀疑整份文档。**
3. **特意点出"轨迹回放不是视频回放"。** 告警页底部那句原文就写了这层区别，值得抬到验收建议里——否则容易被当成"视频能力已经接了一半"。
4. **三种说法（尚无授权 / 未接入 / 读取失败）继续单列。** 代码里有注释强调不可混；文档不点破的话，验收方会以为系统时而这样说时而那样说，是不稳定。
5. **"校验异常"仍与其余分开。** 其余都是"拿不到"，只有它是"拿到了但不对"，需要追查。
