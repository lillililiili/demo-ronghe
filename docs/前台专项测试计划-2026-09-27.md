### 5.3 六条完整链路

1. **正常飞行**：有效计划输入 → MQTT 连续观测 → 融合感知 → 计划匹配 → 可靠合法 → 正确显示轨迹 → 不误触告警/反制。覆盖 SIT、FLT、LEG、STA。
2. **违规经审批处置**：明确违规 → 告警核实 → 模拟短信/电话与位置观察 → 普通申请 → 独立审批 → 模拟设备执行与可信回执 → 按启用能力交接 → 送达签收 → 证据/统计对账。覆盖 ALM、NTF、CTR、HND、EVD。
3. **直接反制及急停**：显式 direct 身份 → 有效依据 → 直接授权 → 实际下发/回执 → 急停 → 停机核查 → 历史保护；核对真实发起人与原授权窗口。覆盖 CTR-05～CTR-16。
4. **误报与信息不足**：待核实事件判误报，另一个依据不足事件停留待确认 → 无通知/反制副作用 → 历史仍可追踪。覆盖 LEG-05～LEG-09、ALM-03/05、NTF-06。
5. **独立风险通知**：计划/空域风险 → 核验 → 通知上级 → 送达/签收 → 风险仍存在 → 收到有效解除依据后退出当前风险 → 历史可查。覆盖 RSK、FLT、AIR、HND。
6. **异常恢复**：通知或设备提交发生超时 → 页面显示未知 → 服务恢复与迟到回执 → 只收敛同一逻辑操作 → 不重复发信/下发 → 多页面一致。覆盖 NTF-10～NTF-14、CTR-10～CTR-15、NET。

第 2/3 条只使用测试设备回执。未接入能力在相应步骤终止并标记 Blocked/不适用及依据，不能用人为修改结果表补完链路。

## 6. 关键判定规则

### 6.1 通知与飞离

- 待核实、误报：不发送飞手短信/电话，不因打开页面触发通知。
- 无已核验执行飞手或短信不可用：按已确认流程进入待反制；该状态不代表具备执行资格。
- 短信送达后开始 T_sms 观察；有有效在域位置且电话可用才进入电话阶段，电话播放完成后开始 T_voice 观察。
- 有效观测证明已离开时停止升级；无新位置不得判为飞离。待反制且无有效观测时，实际反制仍须阻断。
- 送出、送达、接通、播放、位置结果各自保留；通道后来停用或数据后来过期不重写过去事实。

### 6.2 反制资格

### 6.3 页面一致性

## 9. 结果记录、缺陷与放行

### 9.1 每个用例的执行记录

| 字段 | 要求 |
| --- | --- |
| 执行键 | 用例 ID + 参数变体 + 运行批次；例如 `NTF-01/短信送达-持续在域/run-01` |
| 版本/环境 | 前后台版本、工作区差异标识、浏览器、权限角色、开关/规则版本 |
| 数据标识 | 目标、事件、授权等关联 ID；来源及观测时间 |
| 实际结果 | 具体可观察事实，不只写“正常” |
| 状态 | Not Run / Pass / Fail / Blocked / Not Applicable |
| 证据 | 关键状态截图、脱敏请求/响应、时间线、审计/指令记录；视频/轨迹保留对象身份 |
| 缺陷与复测 | 缺陷编号、负责人、修复版本、复测结果及相邻流程回归 |

每个并列变体单独登记结果；部分变体通过不能把整行标为通过。用例默认全为 Not Run。Blocked 记录缺少什么、影响哪些用例、由谁解除；Not Applicable 需说明与当前交付范围的关系并由负责人确认。

缺陷分级：S1 为越权、误下发/重复反制、急停失效、敏感泄露或历史事实破坏；S2 为关键流程不可用、错对象/错状态/核心统计；S3 为一般功能与明显展示问题；S4 为轻微体验。优先级 P0/P1/P2 用于安排测试，和缺陷严重程度分开。

### 9.2 放行标准

1. 适用的 P0 全部执行通过；S1/S2 零未解决；关键链路和权限没有 Blocked。P0 不能因排期豁免。
2. P1 全部执行且默认通过；残留非阻断问题必须逐项由业务负责人接受，列出影响和修复计划。P2 延后明确范围。
3. 所有模块至少覆盖正常、空数据、接口失败、无权限与跨对象切换；跨页数据/来源/历史无错误。
4. 自动化报告列明实际通过、失败、跳过及环境；跳过不计通过。通过率同时报告执行覆盖率，不能靠少跑提高通过率。
5. 真实接入能力若属于本次交付则必须有真实验收证据；未接入项若不在本次范围，在报告明确排除，不包装成全系统通过。
6. G-01～G-07 各有处理结果；尤其通知时长、自动反制范围和测试数据入口差异不得遗留为不明假设。

统计口径：执行覆盖率 = (Pass+Fail)/适用实例总数；通过率 = Pass/(Pass+Fail)。Blocked 和 Not Run 留在适用总数内，单独列出；不适用项经确认后排除。分母为0时写“未执行”，不写100%。
