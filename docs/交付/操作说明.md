# 操作说明（值班员）

**给谁看**：低空安全值班岗。这份说明按**一个班次的实际顺序**写：接班看什么、有情况怎么办、要动设备怎么走审批、下班交什么。不是功能清单，用不到的页面这里就不提。

**内部依据见 `docs/交付/内部依据/操作说明.md`。**

**一句话原则**：平台只显示它真的知道的事。屏幕上写"暂不可用""无读取权限""不可判定"的地方，是系统在如实告诉你它不知道，**不要当成"没问题"**。

---

## 一、接班（约 5 分钟）

### 1.1 登录

打开平台地址，输入账号和密码。管理员把账号标为"需要改密"时，登录后会先跳到修改密码页，改完才能进业务页面。

### 1.2 先看"我的工作台"

登录后默认进"我的工作台"。这是值班的主页面，三类待办都汇总在这里：

顶部五个方块：**全部事项 / 高等级事项 / 无人机告警 / 飞行计划风险 / 设备告警**。点其中一个，下面的清单就只剩那一类（点"高等级事项"是按等级筛，不是按类）。

接班时按顺序看三件事：

1. **五个方块的数字**——心里有数今天堆了多少，其中"高等级事项"是要先看的。
   - 某一类显示"无读取权限"，说明你的账号看不了这类，找管理员；
   - 显示"设备归属映射未配置"，说明设备还没归到你的机构下，找运维。
   - **这两种都不是 0，别当成"今天没事"。**
2. **清单里排在前面的**——按等级和接收时间排序，越靠前越急。
3. **每张卡片最后一行"下一步：xxx"**——直接告诉你这条该干什么。按钮是灰的时，旁边写了原因（比如"当前账号只能查看，不能提交核实结论。"）。

### 1.3 需要看全局态势时

左侧菜单"感知监测 → 融合感知"。地图上：

- 目标停鼠标可看悬浮卡：编号、类型、合法性；有数据时还会多出三行——风险等级、违规事由、处置状态。**缺哪行就不显示哪行**，不是漏了。
- 禁飞区里**中间不填充的那一块是"孔"**，那是禁飞范围里合法可飞的区域，不要当成禁飞。
- 有的目标只有一条从设备指出去的**方位线**，没有点位。那是只报方位、报不出位置的目标，线的起点是上报它的设备。**设备没有登记坐标时线也不画**——宁可不画，也不给你一个假位置。

## 二、来了一条无人机告警

### 2.1 核实（值班员自己做）

工作台点"无人机告警" → 选中那条 → 右侧流程条四步：**告警接收 → 人工核实 → 联动反制 → 通知处罚部门**。

点"**人工核实**"，选结论后提交。

两个结论，选项上写着各自的后果：
- "**属实（置为"已核实，待处置"）**"——属实**只表示已核实**，不表示已经处置了；
- "**误报（终态）**"——选了就结束，不再往下走。
- 如果按钮是灰的，说明你的账号只有查看权限，把这条交给有核实权限的同事。

也可以在左侧"事件处置 → 告警事件"里做同一件事，那里还能同时看到核实历史、关联目标和证据链。

> 没有证据查看权限时，证据链那块会写"当前账号没有证据查看权限，无法汇总证据链。"——这是权限问题，不是没有证据。

### 2.2 需要反制或信号干扰（两个人）

核实属实后，卡片的"下一步"变成"**联动反制**"。

**第一步 —— 你来申请**：点"联动反制"，在弹窗里选动作类型（联动反制 / 信号干扰），填申请事由，提交。提交后状态是"**待审批**"。

**第二步 —— 换人审批**：**批准人不能是申请人**，必须由另一位有审批权限的同事登录，进"事件处置 → 处置与处罚"，在"处置授权"里找到这条，点"**审批**"。

- 弹窗默认结论是"批准"，也可以选"驳回"（驳回必须写审批意见）。
- 批准后这一行立刻变成"已批准"，并显示有效期与审批人，按钮变成"**执行**""**停止**"。

**第三步 —— 执行**：点"执行"。

- 凌云协议设备：下发指令后**等设备回执**，回执成功才算完成；超时或失败会如实标为执行失败。
- 人工执行的通道：按钮是"**登记执行结果**"，现场处置完回来如实填成功或失败和经过。
- 设备没登记连接、协议不支持时，页面会写明"执行受阻"的原因，**不会假装成功**。

**要中止**：点"停止"，填停止原因。停止会立即撤销授权并尝试让设备急停；**设备不支持急停时授权仍然停止**，这一点会记在处置经过里——"授权停了"和"设备真停了"是两件事。

> 屏幕上按钮少了一个不是坏了：能点哪些动作由服务端按这条授权的状态和你的权限逐条下发，不该你点的**根本不显示**。

### 2.3 要走处罚（两个人）

在"告警事件"页选中这条告警，点"**提交处罚交接**"，选接收方后提交。（处罚交接要选接收方；风险的"通知上级"不用选，两者不一样。）

**提交成功只表示材料入库，不等于对方已经收到。** 送达与回执要看"处置与处罚"页里这条交接的投递状态。

到"事件处置 → 处置与处罚"，选中这条交接，右侧按顺序办：

1. **立案** → 生成案件编号
2. **指派承办人**
3. **拟定裁量** → **确认裁量**
4. **提交复核结论** —— **换人**。复核人不能是承办人。
5. **生成决定书** → 可"预览全文""复制全文"
6. **结案**

中途发现不该办：用"**撤案**"；文书出错用"**作废**"；材料缺东西用"**新增待补线索**"，补齐后点"**标记已补齐**"。

> 全过程只在本平台内办理：**不会自动报送外部处罚系统**；决定书是平台内生成的演示文本，没有法律效力，也不提供下载，只能在平台里预览与复制。复核结论同样只记录在本平台，不会自动提交上级法制机构。

## 三、来了一条飞行风险

工作台点"飞行计划风险" → 选中 → 流程条三步：**风险发现 → 人工核验 → 通知上级**。

1. 点"**人工核验**"，提交结论。
   - 核验通过 → 状态进"**待通知**"。**通过只表示核验完了，不表示已经通知了上级。**
   - 判定无需通报 → 选"已排除"，流程条走到"已排除"。
2. 需要通报时点"**通知上级**"。弹窗里**不用选接收方**——系统按配置好的默认接收方发出，你只要确认这条要通报，点"提交通知"。
3. 提交后看"通报记录"这一页签：一行里给出接收方、提交时间、投递状态和回执。
   - 回执写"**已回执 · 已驱离**"——**这条就闭环了**，风险状态自动变成"**已通知**"，不再往处置走。
   - 回执还停在"等待回执"、或投递状态是"发送失败"——**没闭环**，风险仍是"待通知"，交班时要交代。
4. 一条风险只提交一次通知。重复点会提示"该风险已经提交过通知"，并自动切到通报记录让你核对，不会重复发出去。

> 演示环境里的回执是**平台自带的模拟通知渠道**立刻给出的（一律"已驱离"），**真实的上级系统还没有对接**。正式环境接通之前，投递会停在"待投递"并标明渠道未接通——那种情况下该走的线下通报照走。

空中异物（鸟群、气球、风筝、孔明灯）的详细情况在"飞行监管 → 飞行计划 → 全部风险事件"里看。该页的"**驱鸟处置**"按钮是灰的——设备指令与作业参数还没确认，本期不能从平台下发。

## 四、设备出问题了

工作台点"设备告警" → 选中 → 流程条四步：**原因与确认 → 下发重启 → 等待回执 → 恢复校验与关闭**。

1. 点"**远程重启**"，**重启原因必填**（写清为什么要重启这台）。
2. 提交后提示"重启指令已受理，等待回执"，流程条停在"等待回执"。
   - **模拟回执不代表真实设备已重启**；
   - 协议没声明重启能力、或设备离线时会失败，异常保持"待处理"，需要现场处理。
3. 收到回执后点"**恢复校验**"。
   - 通过 → "恢复校验通过，异常已关闭"；
   - 不通过 → "恢复校验未通过，异常仍待验证"，并给出原因，**异常不会关闭**。

设备的实时状态、最近航迹和回执在"运维管理 → 设备实时监测"里看。读不到时页面会写"实时监测数据加载失败""所选设备状态加载失败"，可以点重试；反复失败就报运维。

## 五、交班（约 5 分钟）

交班前把这四件事讲清楚，页面上都能直接查到：

| 交什么 | 在哪看 |
| --- | --- |
| 还剩多少待办、哪几条急 | 我的工作台顶部五个方块 + 清单前几条 |
| 有没有正在执行的处置 | 处置与处罚页"处置授权"里状态为"已批准""执行中"的行 |
| 有没有等回执的设备指令 | 工作台"设备告警"里停在"等待回执"的 |
| 本班做了什么 | 系统管理 → 审计日志，按时间倒序，操作人、模块、动作、时间都有 |

**特别要交代的**：任何停在"待审批""等待回执""待通知"的事项，都要跟接班人说一句——这三种状态都是**在等别人**，不会自己往前走。风险那一类要看清是"待通知"（还没提交或回执没回来）还是"已通知"（回执已驱离、已闭环）。

## 六、常见疑问

**Q：菜单比同事少几项？**
按角色收起来的。复核岗默认只有六项：我的工作台、融合感知、飞行计划、告警事件、处置与处罚、设备实时监测。直接敲地址会看到"无法访问『页面名』——如需访问，请联系系统管理员调整角色权限。"

**Q：按钮是灰的？**
把鼠标停上去，会写明原因——要么是你的账号没这个权限，要么是当前状态不允许，要么是这项功能本期未接入。

**Q：某个数字显示"—"，说明行写着"暂不可用"？**
那项功能还没接进来，或者这次没读到，**不是 0**。说明行会写清是哪一种，不要当成"今天没有"。

**Q：列表是空的？**
空列表就是真的没有数据。它和"无读取权限""暂不可用"是三回事，平台刻意分开显示。

**Q：筛选里"区域"只有一个"不可用"？**
区域字典暂时读不到，鼠标停在下拉上会说明原因。这时候别用区域筛，用其他条件。

**Q：导出在哪？**
告警事件页和"全部风险事件"列表可以"导出 CSV"，导出的内容与当前筛选和排序一致。**飞行计划列表本身没有导出入口。**

## 七、需要甲方确认的一件事

系统对**处置授权的审批**和**处罚案件的复核**强制两个人参与：批准人不能是申请人，复核人不能是承办人。如果现场是一个人值班，这两处走不过去，需要确认排班或再配一个账号。
