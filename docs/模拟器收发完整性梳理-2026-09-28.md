# 模拟器收发完整性梳理

核对日期：2026-09-28。范围：`tools/device-simulator/` 与当前 `E:/houtaiguanlii/server/` 接口、协议映射。依据为当前源码、既有协议契约和自动化检查，不代表真实设备或第三方系统实机联调通过。

## 结论与本次修复

速度是已确认的模拟器漏发：目标编辑器有速度，原先仅用于推进位置，MQTT 目标报文没有 `speed`。本次已补齐标量速度，雷达/5G-A 同时补齐三轴速度，后端可用 X/Y 得到航向。位置、速度来自同一活动轨迹段；转弯更新方向，终点停留上报 0，撤离采用撤离速度。TDOA 仅增加公共 `speed`，不套用其他类型的扩展字段。

其余内容本轮完成梳理，未批量新增功能。特别是既有只读收件箱、设备命令执行和真实渠道配置，没有因本次检查而放宽。

## 二、平台向设备下发及设备回执

`server.py` 中 MQTT 客户端执行 connect/publish/等待发布确认，无主题订阅或命令处理器。因此目前能检查“发出报文并得到 Broker 确认”，不能靠本工具证明“设备收到了业务命令并执行”。

缺少的测试能力包括光电跟踪/停止、设备控制参数、命令序号关联、重复命令幂等、执行失败、执行超时、断线后回执、急停及实际停机确认。平台已有独立的 `LocalRiskVideoEoSimulator`、`LocalCountermeasure4ChSimulator`，它们不是本 Python 模拟器的接收能力，也不代表真实视频或射频设备已执行。

依据：[server.py](../tools/device-simulator/server.py)，后端上述两个独立模拟类。不同设备命令协议需分别核对，不统一伪造“成功”。

## 三、外部系统向平台提交

| 外部输入 | 当前字段/动作覆盖 | 核对结论 |
| --- | --- | --- |
| 新建飞行计划 | message_id、route 或兼容的 route_version_id、uav_sn、start_at、end_at、filing | 新报文直接携带完整航线几何，系统接收后保存并绑定航线版本；旧 route_version_id 报文兼容，不再要求先做几何匹配 |
| 计划申报资料 | 来源、报送单位绑定、报备单位档案、执行飞手档案、单位/飞手申报名称、起降点名称及成对 WGS84 坐标 | 当前表单和 LocalPlanFilingDtos 对应；未关联档案不应被解释成已验证飞手 |
| 补录计划资料 | 按计划读取、expected_version、message_id、filing 提交，展示 PLAN_FILING 接收记录 | 已接通；只补资料，不修改既有航线/时间/执行状态 |
| 天气预报 | plan_id、area_name、published_at；各时段 from/to、天气、温度、风速、阵风、风向、降水概率、湿度 | 当前 WeatherInput/Period 定义的字段都有表单及提交；最多 48 时段，校验顺序与范围 |
| 上级空域下发 | 新增/更新、撤销；消息编号、递增 revision、空域编号、名称、类型、边界、高度上下限/基准、有效时段、归属范围、原因 | 与 UpstreamAirspaceService 允许字段对应；撤销只发其允许字段，保留实际接收结果 |

没有当前正式接口支持的“审批结果回调、计划撤销、外部新增航线”等能力，不能当成仅补一个表单字段即可完成。预报表单也不提供 DTO 未定义的能见度、降水强度等；这些属于平台契约/需求扩展。

已确认的限制：

1. context 的航线、计划与输入历史各有 100 条查询限制，没有完整分页。航线版本又仅选符合条件的一版，不能视为所有可选资料。
2. 模拟器提交到本机专用接口。天气保存后由计划天气查询读取；真实气象供应商接入状态与本机预报成功是两回事。
3. 外部空域下发和 MQTT 场景的旧区域 seed 路径仍并存，尚未统一；不是同一条接收回执链。当前 README 已明确这一点。

依据：[external.js](../tools/device-simulator/web/external.js)、[plan-form.js](../tools/device-simulator/web/plan-form.js)、[weather-form.js](../tools/device-simulator/web/weather-form.js)、[airspace-form.js](../tools/device-simulator/web/airspace-form.js)；后端 `LocalInterfaceDtos`、`LocalPlanFilingDtos`、`LocalInterfaceSimulatorService`、`UpstreamAirspaceService`。
