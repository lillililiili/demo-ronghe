## 运行

在本目录 `dongying-vue/` 下：

```bash
npm install
npm run dev        # http://localhost:5173（hash 路由与旧版地址完全兼容）
npm run build      # 构建 dist/，历史离线瓦片不复制进产物
npm run preview    # 生产产物预览
```

“我的工作台”前台模块已移除，包括菜单、页面组件、专用样式和前台接口适配。默认首页、登录后的默认落点与“首页”链接改为融合感知；旧 `#/workbench` 地址重定向到 `#/situation`。后端接口、历史记录及其他页面共用的核实/通知能力保留。

运维管理、系统管理的菜单入口已移至同级 `houtaiguanli` 后台，业务前台不再展示这两组菜单。六个旧管理地址保留迁移提示，不自动跨系统跳转，也不再加载旧管理页面组件。

业务前台侧栏采用固定分组标题与平铺页面入口，每个页面有独立图标，图标、选中高亮与发光效果统一使用蓝色；分组和整栏均不再提供展开、收起操作，切换页面仅更新选中项。飞行计划“计划信息”标题旁不再显示“查看关联风险”按钮，风险仍可通过“全部风险事件”页签及计划风险记录查看。

合法性研判（`#/legality`）的“全部无人机”列表只展示已明确识别为无人机的飞行、计划与航线研判，顶部统计、分页和目标跳转使用同一范围；没有匹配计划的无人机仍保留。鸟类、气球、风筝及类别未知目标不进入该页，已有非无人机风险继续从空域监测或飞行计划的全部风险事件查看。详情回读发现目标类别变化时停止展示该条研判及操作。此范围依赖后端 `object_type_code` 查询与详情字段，接口失败显示错误，不使用旧范围降级。

2026-09-17 [合法性自动判定 Spec](../docs/superpowers/specs/2026-09-17-legality-auto-decision-design.md)已继续实施：后端按计划、空域、轨迹规则计算并保存证据充分性；可靠明确的合法/非法结果，右侧均隐藏人工任务区和主复核按钮。依据不足时显示“核对信息缺口”，无权限时只读原因；“信息待核对”读取后端实际待处理队列。依据和历史保留，自愿纠错放在“更多操作”。需配套后端新增迁移与 `decision_assurance` 字段；旧记录或旧服务响应未提供结果时如实显示可靠性未知。首版没有经过真实样本的统计准确率验收。

业务数据和登录会话调用 Spring Boot `/api/v1`。平台唯一后端位于同级后台仓库 `../../houtaiguanli/server`，在该目录以 `local` profile 启动；Vite 默认将 `/api` 代理到 `127.0.0.1:8081`。本仓库不再维护 Java 后端。部署到不同 API 根地址时设置 `APP_PUBLIC_API_BASE_URL`，值可为 `/api` 或已包含 `/v1` 的完整地址。

告警详情和处置授权详情的急停区按当前事件展示：尚未取得适用处置或停止记录且查询失败时，只显示紧凑的状态提示和可用的重新查询入口；已有适用处置、停止记录或操作结果未知时，保留完整面板。查询失败不代表无需急停或设备已停止。

仅在任务需要旧版对照且参考工程实际存在时启动其服务；本仓库不提供旧版 `serve.js` 启动入口。当前业务验收以真实路由、接口状态与本次授权的交互变化为准。

详情栏默认隐藏，不显示空白占位；点击记录或地图对象后才展开右侧详情。未选中对象时，地图占用左侧列表之外的全部宽度，列表宽度保持不变。

已有业务风险记录在右栏使用与飞行计划“风险详情与处理”一致的信息结构和视觉组件：风险概览、等级/状态/高度、光电追踪与视频、事件信息、风险依据、核验历史，以及“通知与回执”页签。核验复用共享弹窗，通知调用同一风险交接接口；待核验时显示核验动作，核验通过后以“通知上级”为主操作，按权限保留纠错入口，已通知或已排除时保留历史。保存后回读详情并同步列表和地图；超时保留幂等键并核对，已提交的不重复提交。

普通监测目标即使未关联风险，也可在具备目标、位置、权限及空闲可用设备时发起光电追踪；核验与通知仍须关联业务风险。当前模拟追踪通过本地后端创建明确标记的目标与任务，不生成风险；成功回执后才显示模拟视频，关闭详情停止页面轮询，不将此描述为自动结束设备任务。纯气象风险不显示无关的光电追踪。详见[普通目标追踪流程](../docs/flow-map.md)。

“空域监测”参照飞行计划的三栏布局：左侧紧凑记录卡片、中间地图、右侧详情，各栏独立滚动。顶部常驻风险类型、等级和明确标注的“筛选”入口；重点区域（接口模式为监测窗口）、范围、状态和时间收纳到默认折叠的“更多筛选”，展开浮层不压缩工作区。筛选即时生效，收起后保留已选条件标签、数量及逐项移除/清空入口。距离、高度和位置口径收纳在可展开的“监测说明”中；缺少有效位置的数量单独以警示色显示，权限、读取失败与重试提示仍直接显示。

`#/airspace` → “空域监测”可切换“模拟演示 / 接口监测数据”。开发服务默认显示模拟演示，生产构建默认读取接口；接口失败不回退模拟。模拟场景独立存于 `src/pages/airspace/airspaceMonitorDemo.js`，不写入目标、风险、设备或通知记录。旧 `public/assets/js/mock.js` 当前已不存在，不作为本模块的数据入口。

点击地图空域或空域列表记录只高亮并查看详情，不自动启用范围筛选。点击详情“查看范围内列表 / 风险”，或在“更多筛选”中选择所选空域，才进入所选空域范围；手动启用后范围跟随当前所选空域。移除范围标签后，继续点选或刷新空域不会重新启用筛选；关闭空域详情时清除该范围。

空域监测与风险记录共用一张风险列表、一组范围/类型/等级/状态/时间筛选和一套分页；“空域列表”入口保留。监测目标通过接口明确给出的 `risk_summary.risk_id` 与风险记录关联，同一风险只占一条；不同风险编号保留各自记录。模拟观测保留模拟标识、距离、高度、数量和运动趋势，未关联风险的真实观测标为“未记录风险”，不虚构核验状态。所选空域与区县范围同时作用于两路数据；时间按风险发生时间或无风险观测的最近发现时间进行 `[开始, 结束)` 筛选。重点区域仅限制模拟场景，监测窗口仅限制近期目标读取，不截断历史风险。地图位置与合并后的筛选结果同步，图层开关独立控制近期位置和风险发生位置。工作区占用页面剩余高度，记录列表与详情各自滚动，地图持续可见；低高度窗口保留页面最右侧的整体滚动。分页固定在左栏底部。点击左侧记录或地图目标时联动中间地图和右侧详情；详细距离、高度、数量和运动趋势集中显示在右栏。定位仅调整地图与选中状态，关闭详情保留筛选、分页和列表滚动位置；缺少位置仍可看详情，定位按钮禁用，不跳转飞行计划风险。读取失败和无权限分别提示，保留另一数据源已读内容。此处布局与选择操作不改变业务风险记录。

无人机机巢周边、重点设施、航线附近、空域边界各有两组目标，七帧样例每十秒循环，可暂停及逐帧查看。机巢指无人机自动起降设施，样例关注其起降点周边的空中目标，不代表机巢设备健康或起飞许可。距离分别为到机巢起降点、设施中心、航线中心线、空域边界的水平距离；高度为海拔高度（AMSL），不与离地高度换算；鸟群按只、气球按个。空域样例展示界外、边界上、界内及跨越平面边界的过程，不推导违规结论，也不修改上级下发的空域台账。运动趋势、水平速度、垂直速度及数量变化均对应前后两个观测点。地图、记录列表及所选目标轨迹使用同一帧数据，场景位置与等级明确标记为模拟。鼠标停在模拟参考点、名称、航线或空域内部及边界时，显示名称、类型和距离参照说明；合法航线也支持悬停查看名称。离开、拖动、缩放、切换图层或筛选后清除提示，提示不拦截地图操作。

地图沿用飞行计划风险事件的鸟群图标、圆点、热区与紫色轨迹绘制。点击目标、左侧记录或详情“定位”查看距离连线与轨迹；图例中可切换目标和热区图层，热区仅表达目标组位置，不代表个体数量。区县与手动启用的所选空域边界限制显示范围；要看全部样例，选择“全市 / 全部重点区域”并移除范围筛选。

## 页面转换配方（逐页 Vue 化的固定打法）

以下仅适用于仍有有效 legacy 母本、且明确要求保持原行为的迁移任务。当前业务页面的布局和流程已多次按用户要求调整，不以恢复旧 DOM 指纹为目标；缺失的旧脚本不重建。

1. 读 legacy `pages/<页>.js` **当前版本**（不要凭旧读缓存——上游在动）。
2. 模块级状态 → SFC 非 setup 的 `<script>` 块（跨导航保持，legacy 约定）；
   若 legacy mount 本就重置全部状态（如 commission），直接放 setup。
3. render() 外骨架 → template（UPanel/UKpis；面板体沿用 U.* 字符串走 bodyHtml，
   **禁 v-html 包裹节点**——元素数必须与 legacy 逐一对应）。
4. mount() → onMounted（U.on 委托绑在组件根上，:key 重挂时随节点销毁）；
   destroy() → onUnmounted（usePageChrome 先注册，保证 disposeAll → 页面清理 → closeModal 次序）。
5. **模块加载期副作用（U.regParams / 数据注入）一律留在 legacy script，SFC 不重复。**
6. 验收：双服务并排，`元素数 + 全文哈希`（textContent 去空白）一致才准登记进 registry.js。
   含 rAF 绘制内容的页（地图比例尺/点型计数）先把这些片段正则中和再比。
   ⚠ 测量前确认视口可见（隐藏标签 rAF 暂停、定时器节流，量出来的是环境不是页面）。
