# 天气模拟接口实施与场景合同

用户已确认沿用天气页面设计，并在没有正式接口文档时先模拟接口。本轮只实现天气预报展示链路，不模拟计划输入或天气传感器协议。

采用后端内置模拟适配器，复用受权限保护的 `/api/v1/flight-plans/{id}/weather-forecast`。相比前端写死数据，这能验收接口、权限和状态；相比独立模拟服务器，不需要额外进程或依赖。后台天气配置增加 `source_mode=live/mock`，默认 live，仅 local/test 环境允许 mock，正式模式不回退模拟。

场景：管理员在后台保存模拟配置，配置版本与更新时间组成批次；区域由配置指定，预报为固定六个四小时时段，有效窗口为保存时起 24 小时。每次读取返回同一批次、同一发布时间和内容，不刷新时间、不写业务数据；24 小时后 STALE，后台再次保存才开始新批次。页面明确显示模拟数据、区域与时段，不认定预报覆盖当前计划时段，不关联气象风险、通知或反制。计划 ID 仅用于沿用既有对象访问校验，所有可访问计划查看相同区域预报。

写入范围：一条 WEATHER_FORECAST 配置及既有保存审计；保护已有计划、设备、风险、通知和历史。数据库迁移只增加模式字段，默认不启用模拟。运行前备份天气配置，模拟启用通过现有后台 API 完成；回退在后台切回真实接入并保存（保留审计，不删除历史）。
