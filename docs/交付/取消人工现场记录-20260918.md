# 取消无人机人工现场记录

日期：2026-09-18。

## 页面与操作

- 告警详情移除“现场情况”“人工补充现场情况”及填写弹窗。
- 告警列表不再由人工观察或通知记录派生“等待观察结果”“现场已确认飞离”等状态；事件核实、反制、交接各自沿用已有事实。
- 短信、电话与移送进度保留。合法性详情和反制申请提示不再引导填写现场记录。

## 服务端

- 人工观察写入停用：OBSERVATION 返回 400 / MANUAL_OBSERVATION_RETIRED；历史材料保持只读，不删表、不修改已应用迁移。
- 通知资格移除历史人工观察的阻断；原渠道时效、接收对象、幂等、真实与模拟边界保持。
- 反制资格不再由人工填写的位置、危险程度或紧急理由决定。沿用 C03.fresh_seconds 校验目标及研判时效，要求当前目标明确为 UAV、事件已核实、最新 ACTIVE 研判关联同一告警且 ILLEGAL / FRESH / SUFFICIENT、未知原因为空。
- 同一资格检查用于申请、执行、排队下发和续链，取消“无人工记录即兼容放行”。权限、审批、设备资格、授权窗口和急停条件继续独立校验。
- 设备急停后的实际停机核查属于设备安全流程，保留；不将它当作无人机是否飞离的观察。

## 交付边界

本次不是第一期自动闭环建设，不新增自动观察窗口、自动飞离解除、自动反制或自动处罚。通知送达不能代表目标离开；无当前依据时也不会借删除表单放行。

用户原有未提交改动保留；本次未提交 Git、未修改历史业务数据、未调用真实通知或设备指令。
