# 业务流映射

## 协作者 B：目标与轨迹只读闭环

本节是当前已接入后端的态势页权威流程。它只覆盖目标、目标详情、轨迹和轨迹点查询；告警、合法性、风险、视频和处置尚未接入，不得从页面演示数据推断其业务流已完成。

### 前置条件

- 用户通过 `/api/v1/auth/login` 取得有效 Bearer 会话。
- 账号必须拥有 `target:read`，且目标同时落在账号的组织/区域数据范围内。
- `local`/`test` 可由受限 Seeder 提供确定性数据；`production`（包括与 `local` 同时激活）不加载任何开发 Seeder。

### 主流程

| 步骤 | 用户动作 | API 与鉴权 | 持久化状态 | 页面结果 | 后续动作 |
| --- | --- | --- | --- | --- | --- |
| 1 | 输入账号密码并登录 | `POST /api/v1/auth/login` | 建立服务端会话；浏览器仅保存会话 ID | 进入有权限的默认页 | 打开“感知监测 → 融合感知” |
| 2 | 打开态势页 | `GET /api/v1/targets`，校验 `target:read` 和数据范围 | 只读，目标表不变 | 按服务端 `total` 拉完全部分页并固定排序；可信 WGS-84 目标绘点，其他目标仅列表展示 | 点击列表或地图目标 |
| 3 | 选中目标 | 并行请求 `GET /api/v1/targets/{target_id}` 和 `GET /api/v1/targets/{target_id}/tracks`；取得轨迹元数据后自动预取第一条 `GET /api/v1/tracks/{track_id}/points` | 只读，目标/轨迹表不变 | 显示经范围裁剪的详情与轨迹元数据，并按服务端 `total` 拉完第一条轨迹的点；不显示凭据、内网配置或原始敏感载荷 | 点击“查看真实轨迹” |
| 4 | 查看轨迹 | 正常点击打开已预取的轨迹结果；切换下一条轨迹或对可恢复错误重试时，再请求对应 `GET /api/v1/tracks/{track_id}/points` | 只读，轨迹点表不变 | 表格区分 AMSL/AGL，地图仅绘可信 WGS-84 点 | 有多轨迹且当前请求未因 403 失败时，可切换下一条 |
| 5 | 查看无 latest 目标的历史轨迹 | 同步骤 3–4 | 只读；不创建 `target_latest_state` | 目标仍标记“无可信 WGS-84 最新位置”；历史轨迹末点仅作为带“历史轨迹”标识的绘制锚点，不冒充 latest | 返回列表选取其他目标 |

有 latest 的目标即使加载了历史轨迹，目标图标和 tooltip 的位置也必须锚定 `target_latest_state.location`；历史轨迹只负责画线。

### 异常和恢复

| 场景 | 页面行为 | 恢复路径 |
| --- | --- | --- |
| 列表/详情/轨迹的网络错误或 5xx | 显示真实接口错误，清空当次数据，不回退 `window.MOCK` | 服务恢复后点击“重试”或“重试真实轨迹” |
| 401/会话过期 | 全局会话机制清除无效会话并进入登录流程 | 重新登录后再进入态势页，不复用过期数据 |
| 403/缺少动作权限 | 显示无权限，不将鉴权失败标记为可重试网络故障 | 由管理员授权或切换到有权账号 |
| 详情对象越权 | 服务端按不存在返回 404 | 返回可见目标列表，不暴露对象是否存在 |
| 空数据 | 显示空列表/无轨迹，不生成演示记录 | 等待真实数据或更换有数据范围的账号 |

### 验收生命周期

- 刷新页面必须重新请求标准 API，不使用前一次内存数据伪装成新响应。
- 重启后端后，`local`/`test` 夹具以稳定 ID 幂等恢复；生产不得生成夹具。
- 断开后端时必须显示接口错误且页面目标数为零，不得回退 Mock。
- 鉴权验收至少覆盖有效会话、401、403、越权 404 以及重新登录。本流程为 Web 只读查询，不涉及 Android 系统返回键或设备状态机，设备验收项不适用。

## 协作者 B：飞行计划、空域事实与已保存合法性研判

本节描述阶段 3A 的只读检查点：服务端提供航线版本、飞行计划、空域版本、空间冲突事实和已保存研判，现有飞行计划页与合法性页只做标准 API 接线。该检查点不包含生产规则计算、自动审批、处置写操作或研判重算，不得称为完整生产合法性能力。

### 前置条件与边界

- 用户必须拥有页面对应的动作权限：计划 `flight:read`、航线 `route:read`、空域 `airspace:read`、研判 `assessment:read`；冲突事实同时要求计划与空域权限，研判历史同时要求计划与研判权限。
- `ASSIGNED` 只认同一条授权记录内的完整 `(owner_org_id, district_id)` 元组；`ALL` 也不返回归属缺失的数据。越权详情与真实不存在统一返回 404。
- `local`/`test` 仅在显式开启开发 Seeder 时写入固定来源的样例；`production` 以及 `production,local` 不注册这些样例。
- GET 只读取已有事实和研判，不创建规则版本、不生成结论，也不修改计划、空域或研判记录。

### 飞行计划与冲突事实流程

| 步骤 | 用户动作 | API 与鉴权 | 页面结果 | 安全降级 |
| --- | --- | --- | --- | --- |
| 1 | 打开飞行计划页 | `GET /api/v1/flight-plans`，校验 `flight:read` 和数据范围 | 按服务端筛选、排序、分页显示计划；数量未知时不从当前页伪造总量 | 列表失败时清空旧列表并显示真实错误，不回退 Mock |
| 2 | 选择计划 | `GET /api/v1/flight-plans/{plan_id}` | 展示计划及其钉住的精确 `route_version_id`，不自动切到航线最新版本 | 越权或不存在统一 404；字段缺失显示未知 |
| 3 | 查看航线 | `GET /api/v1/route-versions/{route_version_id}`，校验 `route:read` | 仅可信 WGS-84 `LineString` 可绘制；高度按返回的 AGL/AMSL 原样显示 | 几何或高程依据不足时不绘制、不换算、不填 0 |
| 4 | 查看空域与冲突 | `GET /api/v1/airspaces`、版本详情和 `GET /api/v1/flight-plans/{plan_id}/airspace-conflicts` | 地图只绘可信 WGS-84 `MultiPolygon`；冲突区分时间、水平和高度事实 | 走廊宽度、边界、版本、时段或高程基准不足时返回具体未知原因；冲突事实不等同合法性结论 |

空间查询以 4326 包络框缩小候选后，必须用 PostGIS `geography` 按米制复核；计划中的走廊宽度按全宽存储、查询半径取一半。边界接触政策未确认时保留 `BOUNDARY_POLICY_UNKNOWN`，AGL 与 AMSL 没有换算依据时保留不可判定。

### 已保存研判流程

| 步骤 | 用户动作 | API 与鉴权 | 页面结果 | 安全降级 |
| --- | --- | --- | --- | --- |
| 1 | 从目标或计划进入合法性页 | 使用深链目标选择计划，再请求 `GET /api/v1/flight-plans/{plan_id}/legality-assessments`；校验 `flight:read` + `assessment:read` | 按服务端 `assessed_at DESC, assessment_id ASC` 分页显示已保存历史，不擅自选择无关计划 | 找不到关联计划时显示空状态，不用首条计划代替深链目标 |
| 2 | 选择一条研判 | `GET /api/v1/legality-assessments/{assessment_id}`，校验 `assessment:read` 和数据范围 | 展示 `LEGAL`、`ILLEGAL`、`UNDETERMINED` 或 `NOT_APPLICABLE`、规则版本、检查项、未知原因和证据引用 | 存储 JSON 或枚举异常时服务端失败关闭并返回 `INTERNAL_ERROR`，页面清空旧详情 |
| 3 | 查看地图和来源 | 复用该研判钉住的计划、航线版本、空域与冲突事实 API | 只展示 API 返回的来源、规则与可绘几何 | 不读取 `window.MOCK`、不在前端执行 C01–C03、不显示 `source_snapshot` 或 `credential_ref` |

页面保留审批、导出、下发和处置入口的视觉位置，但阶段 3A 内全部禁用，不能伪造成功提示。刷新必须重新读取标准 API；后端中断或 401/403/404/5xx 时必须显示真实状态并清除过期数据，服务恢复或重新登录后再显式重试。

### 验收生命周期

- H2 验证接口参数、权限顺序、范围元组、分页排序、越权 404、字段降级和生产 Seeder 隔离。
- 真实 PostgreSQL 16/PostGIS 验证迁移、WGS-84 约束、版本不可变、米制半宽缓冲、边界接触、高程/时间关系与固定 local 空间样例。
- 浏览器验收覆盖飞行计划页、风险页签、合法性页、目标深链、刷新、断后端、空数据和不同视口；接口失败不得切回演示引擎。
- 阶段 3A 之后仍需业务确认权威来源、走廊宽度口径、边界接触、高程换算、规则阈值和重算制度，确认前不得把 Mock 样例等同生产合法性。
