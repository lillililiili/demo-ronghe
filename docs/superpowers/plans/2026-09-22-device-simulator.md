# 设备信息模拟器实施计划

> 后续用户明确要求接现有系统、通过 MQTT 发数据，并确认 5D-A 为 5G-A。下方早期“本地运行优先”和“本地风险判定”设想已被替代，以本段与工具 README 为准。

## 实际实施与验证

- [x] 独立本机模拟器：注册 replay 设备、配套计划与区域、发布 MQTT、回读平台目标与研判。
- [x] 雷达、5G-A、TDOA 工参及目标轨迹；光电心跳；离线/故障时间窗；暂停/继续/停止；运行快照、持久日志与导入导出。
- [x] 只新增独立批次，不修改历史记录；Broker PUBACK、后台消费和系统业务结果分别显示。
- [x] 六项引擎单测、语法检查、两次 30 秒本机 MQTT 验证及浏览器连接/回读验证。

实际回读：4 台设备、1 条计划、1 个区域、1 个融合目标、6 条研判、0 条告警；系统结论为不可判定，如实保留。气象 MQTT、气球分类码、光电跟踪回执尚未接入；原始高度可以上报，但现有后端的高度基准未确认，不能保证超高告警。使用说明见 `tools/device-simulator/README.md`。

## 早期计划（以下范围已被上文替代）

**目标：** 基于已确认页面与操作逻辑，交付独立可运行工具；保留原设计稿。用户本轮已要求据此实现，不重复设计审批。

**架构：** Python 本地进程托管页面与时间驱动模拟引擎；编辑器通过同源接口提交冻结场景快照、查询运行状态、暂停和停止。模拟器不是平台业务后端，不注册业务路由、不修改数据库。MQTT 复用现有协议字段和 paho 客户端，默认本地模式；主动配置才可发送。

**技术：** 原页面 JavaScript/CSS/SVG；Python 标准库；现有 paho-mqtt 仅用于 MQTT。

- [ ] 实现输入校验、定速轨迹、九类风险的本地几何/时段检查、设备故障时间窗与离线停报。明确本地结果不能替代平台研判。
- [ ] 实现本地任务状态、日志导出、同源控制接口、暂停/继续/停止、有限时长；错误停止，不自动重发未知结果。
- [ ] 复用页面接入运行控制、状态与日志、场景导入导出、连接配置；保存与运行快照独立。
- [ ] 使用隔离场景验证时钟、几何、异常恢复、输入拦截及并发停止；浏览器验证运行与配置。

MQTT 契约：雷达/TDOA 使用 LingyunEnvelope，光电心跳使用 EoEdgeEnvelope；5D-A 不等同 5G-A，气象不硬塞入 MQTT。未映射类型在 MQTT 模式阻断启动。光电目标跟踪协议需要真实任务关联，本版不造跟踪回执。平台设备预登记、计划/区域配套及通知隔离由测试环境准备，本工具不自动写业务库。

运行批次：每次启动唯一批次，目标和设备身份在同一次运行固定；运行时间上限 20 分钟；日志为模拟来源。默认本地运行只在工具内产生报文和预期风险；MQTT 确认只代表 broker PUBACK，非平台入库、报警或真实通知结果。
