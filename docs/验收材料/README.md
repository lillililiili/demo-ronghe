## 环境与账号

只在**隔离开发库**上走这些用例。不要用生产库。

- 后端：`server/`，`local` profile，`app.dev-seed.enabled=true`（见 [server/README.md](../../server/README.md)）
- 前端：`dongying-vue/`，`npm run dev`，默认 `http://localhost:5173/`
- 数据库：`deploy/compose.yml` 的 `db`。凌云 MQTT 回放再启 `mosquitto`（只绑 `127.0.0.1:1883`）
- 账号（种子，密码可用 `APP_DEV_SEED_PASSWORD` 覆盖，缺省 `changeme`）：
  - `admin1`：内置超级管理员，全菜单、全动作
  - `reviewer1`：`ROLE-DEMO-REVIEWER`，审批/复核用第二人；**不能**批自己申请的处置，**不能**复核自己承办的处罚（决策 15-3）

本机演示设备（`local` 种子，**不是现场设备**）：

- 凌云 MQTT 回放：`S85R1` 雷达、`S85T1` TDOA、`S85A1` AOA、`S85G1` 5G-A、`S85D1` 协议破解、`S85I1` RemoteID、`S85Y1` 诱骗、`S85F1` 干扰、`S85B1` 驱鸟炮、`S85E1D1` 光电
- 四通道回环：`CM4-LOCAL`，`127.0.0.1:10006`，`source_mode=live` 且 `simulated=true`
