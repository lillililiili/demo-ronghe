# 口径说明书

2026-09-09。验收时把下列标注当成**诚实缺事实**，不要当成缺陷单。词义以本表为准；出现次数会随版本变。

历史引用：《系统未完成项盘点-2026-09-08》曾写「73 处 `UNAVAILABLE`、42 处尚未接入、12 处不可判定」。那是当时全库粗数，**不要再当当前缺陷数**。

| 说法 | 抽样范围 | 约数 | 说明 |

## 2. 词义

| 说法 | 含义 | 不是 | 常见出处 |
| --- | --- | --- | --- |
| `UNAVAILABLE` / 暂不可用 | 这一格没有可展示的事实：缺权限、缺服务、缺空间后端、或缺依据 | 进程宕了、接口 500 | 飞行对照 `SECTION_AVAILABILITY`、空间风险评估、证据链文件缺失、`ADAPTER_UNAVAILABLE` |
| 尚未接入 | 产品上有入口，本切片没有真实通道或没有接到后端口径 | 按钮坏了、权限配错 | 实时视频、通知机场、飞行计划导出、合法性「转入处置」、驱鸟处置 |
| 不可判定 / `UNDETERMINED` | 规则或调测**跑过了**，但输入不够，不给合法/非法或通过/失败 | 引擎没开、任务没跑 | 合法性结论、计划匹配、高度带、调测 `UNTESTABLE` |
| 设备协议未提供 | 厂家报文没有这条能力，平台故意不实现 | 开发遗漏 | 急停 URL、光电角度移动 / home / 辅助识别 |
| `DEMO` / 演示策略 | 阈值、时限、指令映射未经客户确认 | 已上线业务口径 | 处置 `demo-v1`、规则集、融合 `demo-v1` |
| `source_mode=replay` | 回放/模拟来源 | 现场设备 | `S85*` MQTT 种子 |
| `source_mode=live` 且 `simulated=true` | 本机回环，协议是真的，射频不是现场的 | 现场已发射 | `CM4-LOCAL` |
| 配置 live | 允许填写真实 broker/TCP 地址 | 现场联调完成 | 接入来源 `source_mode=live` |
| 尚无授权 / 尚无引擎研判 | 查过了，确实没有记录 | 读失败 | 工作台流程条、飞行 KPI「本页」 |
| `NO_EVALUATION` | 还没有研判结果 | 研判失败 | 飞行对照 |
| `PROTOCOL_NOT_OPENED` | 指令码不在 A 的协议白名单（如 50000） | 设备离线 | 处置执行受阻 |
| `NOT_BOUND` / 未登记凌云连接 | 没有 `mqtt_device_binding`，运维可补 | 厂家没做急停 | 处置凌云 B 通道 |
| `DEVICE_OFFLINE` | 未启用或不在线 | 协议未开放 | 处置执行 |
| `DEVICE_CAPABILITY` | 所选设备不能走该通道（例如四通道通道配了雷达） | 等厂家开码 | 处置四通道配错设备 |

## 3. 高度与坐标

- 凌云协议 A 写「海拔高度」，B/C 写「椭球高」。**客户确认前**：高度只留在 payload/`quality.altitude_raw`，不进合法性超高比较，页面不得编出「超高成立」。
- 光电与 AOA 的协议 A 位置无效，必须空着；AOA 用方位。无位置时态势可画方位线，**不以 (0,0) 补点**。
- 雷达 TCP 无站址 RTK / 北向时不派生 WGS-84。

## 4. 控制与停止

- 凌云停止：同一指令 `operationType=0`，不是急停。
- `POST .../emergency-stop` 固定 `409 CONTROL_NOT_ENABLED`，文案「急停：设备协议未提供」。
- 四通道停止：`SET_MASK` `mask=0`（全关）。成功记 `DEVICE_ALL_OFF_ISSUED` / `device_stop_result=ALL_OFF_ISSUED`。**不叫急停**。
- 本机四通道回执成功 **不代表射频已发射**。

## 5. 怎么验收这些格子

1. 看屏幕原文是否落在上表某一行。
2. 看 title / 说明是否指向补救方（换设备、补 MQTT 绑定、开规则引擎、等厂家、等客户确认高度）。
3. 不要因为出现「尚未接入」就开缺陷；只有**该有事实却写成尚未接入**、或**编造了结论**才算缺陷。
