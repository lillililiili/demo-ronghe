## 旧稿里的两条附带发现（本文未处理，转交）

1. **设备页「接收诊断」会把英文码直接显示到屏幕上**（形如 `REJECTED · UNSUPPORTED_TYPE`），
   与「页面不出现英文码」的约定不符。属于前端文案问题，不在本任务范围，已单独报给领导。
2. 光电「抓拍 / 录像」曾被盘点为已建，**实为误判**——匹配到的 `record` 是 Java 关键字，
   并非录像能力。正文第七节按「没有任何协议定义图像回传、靠人工上传」为准。
