# 天气预报取消过期判断（2026-09-23）

用户确认“这个天气预报不存在过不过期”。本次取消天气预报的过期分类、提示和到期刷新。

飞行计划 → 天气预报仍按计划起止时间筛选、裁剪预报时段。发布时间、来源及模拟标记保留；没有时段覆盖时显示“计划飞行时段暂无天气预报”，计划时间不完整及读取失败分别展示。旧接口返回的 STALE 预报按同一规则显示。

后端的配置模拟预报与按计划接收的外部模拟预报均不再按当前时间返回 STALE。读取保留原发布时间和 from/to，不修改历史接收记录。后台接口配置取消“到期后重新保存”提示，并兼容旧 mock / STALE 状态。气象风险的有效时段判断未修改。
