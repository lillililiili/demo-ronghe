# 信号模拟器五组演示样本

用户已确认将上一轮五组方案配置到模拟器并运行。本轮在本地 main 实施，保留已有改动。

## 范围与关联

- 单次 15 分钟，Asia/Shanghai 当天有效计划与区域；每次新批次，旧记录保留。
- deviation-uav → deviation-plan：先在走廊内，再连续偏离。
- zone-uav → zone-plan + restricted-zone：先在区域外，再进入有效禁飞区域。
- unmatched-uav：无计划，保留授权依据不充分。
- birds → bird-plan：鸟群接近并进入航线，不进入无人机合法性流程。
- fault-radar：60 秒后故障，持续 120 秒，再上报正常；不承载上述目标，避免干扰主线。
- MQTT 只发送观测；目标、研判、告警及风险由后台派生。通知通道当前 NONE，不修改全局配置；反制和自动移送缺口如实保留。
