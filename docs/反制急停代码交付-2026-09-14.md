## 画面和操作变化

| 之前 | 现在 |
| --- | --- |
| 停止藏在单条授权操作中 | 当前事件卡片直接显示红色急停，范围注明反制及关联干扰 |
| 停止与填原因绑在一起 | 先发起停止，再补原因；设备反馈与操作记录留在同一处 |
| 授权终止后难以判断设备是否停止 | 排队、等回执、全关确认、离线、不支持和现场确认分别显示 |
| 网络失败后容易重复提交或无法继续 | 先查询；仍未证实可重试同一请求，沿用原幂等键 |
| 旧记录可能干扰新一轮展示 | 当前处置与上次停止记录分开，新一轮仍按申请审批流程进行 |
