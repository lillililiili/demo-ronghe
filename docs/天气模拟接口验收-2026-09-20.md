# 天气模拟接口与验收

用户在正式接口文档缺失时授权先模拟。当前业务页“飞行计划 → 天气预报”通过实际后端 API 显示东营市模拟预报；管理端“运维管理 → 接口配置 → 天气预报”选择模拟接口并保存，页面显示模拟已启用。正式天气、计划输入以及传感器协议仍未接通。

模拟预报只服务展示，包含六个四小时时段及温度、风速、阵风、风向、降水概率、湿度。区域由后台配置；预报并不代表已匹配计划航线或计划时段，也不生成风险、设备上报、通知、研判和统计。发布时间固定为本批配置保存时间；读取不刷新时间，不写入业务事实；24 小时后过期，后台重新保存才产生新批次。前台明确标注模拟及北京时间，到期或休眠恢复后重新读取；离开时清理计时器。

## 配置与接口

- `source_mode` 取 `live/mock`，默认 `live`，只有天气配置接受 mock。模拟必须填写区域，只允许 local/test 且没有 prod/production profile；生产环境拒绝保存模拟、拒绝返回模拟预报。
- 原配置权限 interfaces.read/op、版本锁和审计保留；预报仍先校验 flight:read 与计划对象范围。
- 模拟有效批次配置状态 SIMULATED、enabled=true；过期 STALE。预报返回 READY/STALE 和 forecast（始终 source_mode=mock）；正式模式未实现时返回 NOT_CONFIGURED/AWAITING_ADAPTER，没有 forecast，绝不回退模拟。
- 新增迁移 V202609200003，仅新增模式列及约束，默认不启用、不灌业务样例。
- 回退：后台切为真实接入并保存，立即停止返回模拟；不删除历史及审计。
