# 直接反制权限实现与验收（2026-09-17）

## 页面怎么操作

1. 后台“系统管理 → 角色管理 → 动作权限 → 反制授权”选择可编辑自定义角色，将“直接反制（免逐次审批）”设为“允许”。默认无权限，不联动其他处置权限；内置角色继续锁定。
2. 业务前台“告警 → 无人机事件详情 → 反制授权”根据当前权限和业务条件显示“直接反制”或“申请反制”。直接入口仍校验事件/目标、范围、设备、有效期和急停阻断。
3. “处置与处罚 → 反制授权”和处罚交接材料显示直接操作人、免逐次审批、执行状态。设备受阻不显示成功，人工通道需登记现场执行结果。
