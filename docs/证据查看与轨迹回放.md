# 证据查看与轨迹回放

适用：2026-09-17 的业务前台实现。入口为告警事件、处置与处罚的证据链，以及证据管理的内容预览。2026-09-17 用户确认预览以内容为主，以下展示规则替代前一天的来源侧栏及技术信息布局。

## 页面行为

- 轨迹卡片展示原始轨迹与 `TRACK_SNAPSHOT` 文件。点击后在同一窗口切换材料，原始轨迹按证据记录的准确 `track_id` 读取，快照仅使用文件自身的点，不取目标最新轨迹替换。原始轨迹预览不再展示“轨迹记录信息”区块（轨迹编号、分层及记录起止时间）；地图、观测时间和回放功能保留。
- 地图默认展示本份材料的完整观测范围；预览支持拖动时间轴以及 1/2/4/8 倍速回放。缺少有效观测时间时保留上一点/下一点；证据详情始终保留逐点操作。回放按观测时间差推进，到末尾停止，隐藏浏览器页面时暂停。
- 仅绘制声明为 WGS84 的有效观测坐标。保留原始顺序、轨迹身份、序号、显式断点；缺坐标、跨轨迹、序号缺口或时间不递增处不连接。不插值、不补点、不平滑。
- 缺少观测时间时可以逐点查看，不能用接收时间冒充观测时间回放。旧坐标数组没有坐标系及观测字段时保留原文和不足说明。快照缺少部分点时标明不完整。
- 当前点接口及快照没有带可核验计划、走廊依据的逐点比对结果，因此本入口显示黄色“航线关系未知”；不会依据快照自填关系或目标合法性染绿、染红，也不生成计划航线。其他页面已有有效比对的颜色口径不变。
- 预览保留 JSON 快照的模拟声明和文件来源模式；RAW 证据摘要及点接口不提供来源模式时如实显示“来源未记录”。坐标、点类型、原始 JSON 及详细解释只在证据详情查看。
- 图片、视频使用完整内容宽度，不再展示右侧来源栏、文件名和缩略文件列表；保留采集时间、模拟/回放标识和必要异常。图片支持缩放、适应窗口、原始尺寸；同组材料使用上一份/下一份切换。
- 视频保留原生播放器和单个倍速切换按钮。前后 0.1 秒、5 秒定位及详细时间读数在证据页保留；不宣称逐帧，不补造录像标记。
- “查看证据详情”按当前材料跳转。文件使用 `#/evidence?file=<evidence_id>`，即使当前台账分页或筛选不含该文件，仍单独读取此 ID；读取失败不以其他文件替代。原始轨迹使用 `#/evidence?subjectKind=<EVENT|TARGET|CASE>&subjectId=<id>&track=<track_id>`，重新读取授权证据链并核对记录归属后展示详情。没有证据页访问或读取权限时明确提示，不开放无权入口。
- 缺失、入库中、哈希异常、销毁、无预览权限、读取失败分别展示。切换记录立即移除旧内容，迟到响应丢弃；关闭后释放地图、播放计时器和 Blob URL。

## 接口与权限

- 不更改后端分类或哈希：后端仍可能将 `TRACK_SNAPSHOT` 返回为 `IMAGE`，前端按 `kind_code` 重组可见卡片，保留原记录及 `integrity`。显示计数取实际返回记录；截断时不把未返回解释为缺失。
- 原始点读取 `GET /tracks/{track_id}/points`，每页 100 条，需 `target:read`。离开当前记录后停止后续分页。
- 文件元数据、预览、下载继续使用现有证据文件接口与各自权限。只有文件查看权限而没有目标读取权限时，仍能查看已获授权的轨迹文件，不读取原始目标轨迹。
- 不改变事件判定、通知、处置流程，不新增入库材料，不修改历史时间、关联或冻结材料。
