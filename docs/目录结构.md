# 目录结构

本文件描述当前代码的目录约定，不代表所有目录中的能力已通过运行验收。流程参考见[事件驱动业务流程梳理](事件驱动业务流程梳理.md)，后端范围和当前实现见[后端开发基线](后端开发基线.md)，开发排期与分工见[后端双人协作开发计划](后端双人协作开发计划.md)。

## dongying-vue/src/assets/css/

```
dongying-vue/src/assets/css/
├── index.css               入口，@import 顺序即层叠顺序
├── tokens.css              主题 token 唯一真源
├── reset.css               全局复位、滚动条
├── visual-2026.css         2026 视觉覆盖层
├── themes.css              body[data-theme] 模块插画
├── layout/                 壳层：顶栏/导航/面包屑/大屏模式
├── mixins/                 通用布局工具类
├── components/             跨页组件类
└── pages/                  单页样式（工作台、用户、合法性、大屏等）
```

改 token 只改 `tokens.css`。改顶栏/导航/面板时同时看 `layout/`、`components/` 和 `visual-2026.css`。

## 同步边界

- `dongying-vue/public/assets/js/**` 与 `dongying-vue/public/assets/img/**` 仍可按 `dongying-demo` 母本对照。
- 样式以 `dongying-vue/src/assets/css/` 为准，不再要求与母本 `app.css` 逐字节一致。
- 产品表单只使用 `dongying-vue/src/components/form/`（`UField` / `UFieldGrid` / `UFormFooter`）。新弹窗走 `openFormModal()`；存量 innerHTML 控件由 `dongying-vue/src/ui/legacyControls.js` 升级，不要再扩大这条兼容路径。

## 后端目录与文档维护

- 后端规则见 [server/AGENTS.md](../server/AGENTS.md)。在 `modules/<业务>/` 下按需组织 `api/application/domain/infrastructure`，保留现有包名；基线中规划的模块不代表目录已经创建。
- 正式测试放 `server/src/test/java` 和 `server/src/test/resources`，构建产物放 `server/target/` 且不提交；前端临时文件约束不禁止后端正式测试。
- 后端数据库迁移放 `server/src/main/resources/db/migration/`，部署示例继续放根级 `deploy/`，不另建一份重复部署目录。
- [后端开发基线](后端开发基线.md)记录业务与事实，[后端规则](../server/AGENTS.md)约束实现，[后端 README](../server/README.md)提供运行入口；变更公共约定时同步最近的文档，避免相互矛盾。
- [数据库设计文档](数据库设计文档.md)描述拟建表和现有表的增量设计，不代表迁移目录中已存在对应 SQL；实际结构仍以版本化迁移及运行验证为准。
