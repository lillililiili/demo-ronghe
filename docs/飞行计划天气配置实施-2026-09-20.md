# 飞行计划天气配置实施（2026-09-20）

## 页面变化

- 业务前台 `#/flights`：右侧“计划详情与风险”新增“计划信息 / 天气预报”切换。计划信息保留原有资料、对照、风险和业务动作；切换天气不销毁原计划办理组件。天气请求按当前计划读取，切换对象或离开后旧请求失效。
- 后台 `/operations/interfaces`：新增“接口配置”，分飞行计划输入、天气预报配置，并提供天气传感器设备管理入口。读取、保存使用原 `interfaces.read/op` 权限；配置版本冲突要求重新加载。
- 后台 `/operations/devices`：增加“登记天气传感器”、类型筛选和专用档案编辑。保存到原设备台账，填写编号、名称、厂家型号、单位/区域和安装位置。默认停用、状态未知；未接入协议不能启用。气象观测页签当前如实显示暂无数据。

## 实现边界

已经实现页面、配置草稿服务端持久化、传感器档案登记、权限/范围/并发检查。没有外部系统资料，因此以下工作仍待对接资料：

1. 飞行计划来源系统及推送/拉取协议；真实接收地址、鉴权、字段映射、版本事件处理与接收日志尚未实现。
2. 天气服务商、接口字段和覆盖区域；真实预报拉取、更新周期执行和数据存储尚未实现。后台保存的是草稿，不能显示连接成功或启用；业务页面当前仅返回未配置/待接入。
3. 天气传感器厂家型号与报文协议；采集适配与真实读数尚未实现，不假设支持六要素、阵风或能见度。

前端已准备按返回字段展示预报发布时间、时段、来源和气象数值的组件；这不代表当前服务已经提供预报。没有新增现场实测页签、计划站点关系、适飞判断或天气风险规则。原有气象风险历史和流程保持不变。

设计评审的紫/橙标记仍只在 `docs/designs/2026-09-20-plan-weather/` 预览中，不进入正式业务操作页。
