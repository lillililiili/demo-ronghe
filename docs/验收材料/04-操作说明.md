# 操作说明（值班员）

2026-09-09。按班次顺序写。功能字典见各阶段契约；缺口见[协议缺口矩阵](02-协议缺口矩阵.md)。

## 0. 上班前

1. 确认连的是开发环境（前端 5173，API 8080），不是生产。
2. 用自己的账号登录。演示库：`admin1` 值班操作，需要第二人时叫同事用 `reviewer1`（密码与 `admin1` 相同，缺省 `changeme`）。
3. 打开**我的工作台**，看有没有「下一步」还没做的事项。

改密码：首次若提示必须修改，按页内流程。会话过期会回到登录页，重新登录后应能回到刚才的业务页（书签 `#/...`）。

## 1. 看有没有飞的东西

1. 打开**融合感知**。
2. 地图上只画有位置的目标；没有位置的 AOA 只画方位线，不要以为没点就是系统丢了。
3. 点目标看风险 / 违规事由 / 处置状态——没有那一行就是没有那条事实，不是漏渲染。
4. 需要盯视频、通知机场：按钮是灰的，标题是「尚未接入」。改用电话或外部系统，不要反复点。

## 2. 告警来了怎么核实

1. **告警事件**里点该行，看等级、区域、关联目标。
2. 没核实前不要发起反制。点「人工核实」，选属实或误报，写说明。
3. 属实后状态是「已核实，待处置」。工作台这件事的下一步应变成处置类动作。

## 3. 怎么申请处置（必须另一人批）

1. 在告警详情或工作台点「发起联动反制」（已有未了结的同类授权时按钮是灰的，不要再提一条）。
2. 选动作：联动反制 / 信号干扰 / 驱离 / 诱骗（以弹窗选项为准）。
3. 选通道：
   - **凌云协议 B**：填干扰/诱骗/驱鸟炮的设备 ID（演示：反制/干扰用 `S85F1`，诱骗 `S85Y1`，驱离 `S85B1`）。设备要在线，且类型和动作一致。
   - **四通道反制设备**：填 `CM4-LOCAL` 的设备 ID（在设备管理里复制）。只适合反制/干扰；驱离、诱骗会报错。
   - **人工执行**：现场做完再登记结果，不填设备也可以。
4. 写事由（至少两个字），提交。此时只是申请，**还不能打**。
5. 把自己登出。请 `reviewer1`（或另一名有审批权的人）打开**处置与处罚**，点该授权「批准」。申请人不能批自己的。
6. 批准后在时限内，有执行权的人点「执行」。
   - 凌云：等设备回执，成功才算完成；超时或失败会标失败，不要口头改成成功。
   - 四通道：经网络控制器下发，回执以设备为准；本机模拟成功不等于现场打到了。
7. 要停：点「停止」。授权会撤销。凌云没有急停，页面会写设备可能仍在动作。四通道会下发**全关**，那不是急停。

## 4. 光电跟踪

1. 目标必须有经纬度。没有位置会提示无法引导。
2. 本地演示环境发现有效告警或高风险目标后，会自动选择同机构、同辖区的在线空闲光电设备开始跟踪。
3. 告警页的「人工补跟踪」只在自动跟踪没有启动时使用；误报不再允许启动新跟踪，已有跟踪可手动停止。生产环境须由运维显式打开自动跟踪开关。
4. 云台转动、回 home、辅助识别：协议没有，页面写「设备协议未提供」，不要报故障。
5. 停止：对进行中的任务点结束。

## 5. 设备值班

1. **设备管理**：查编号、启用/停用要写原因。四通道编辑页说明：调测只查状态，真动作走处置或控制命令。
2. **设备实时监测**：看在线、频段、异常单。重启只有协议声明了才能用；雷达和四通道会拒绝重启。
3. **设备接入调测**：新设备先连上再跑任务。四通道调测通过 ≠ 允许发射。雷达待机没航迹可以是「不可判定」。

本机演示：

- MQTT：按 [server/README.md](../../server/README.md) 发 NDJSON；不要改冻结的 180 行文件。
- 四通道：后端 local 会自己在 `127.0.0.1:10006` 听；不要去连现场 `192.168.0.7`。

## 6. 飞行计划与合法性

1. **飞行计划**看报备是否在执行、是否偏离。通知上级点过一次就不要再点。
2. **合法性研判**看结论。写着「不可判定」时不要当成「合法」或「非法」。高度有争议时不要对外说超高已认定。
3. 「转入处置」若显示尚未接入，改从告警或工作台走第 3 节。

## 7. 处罚与证据

1. 处罚在**处置与处罚**页。立案、裁量、文书、复核按按钮走；复核人不能是承办人。
2. 决定书带「演示模板 · 未经授权出具」时，不能当正式文书。
3. **证据管理**只下载和看引用。缺文件下不了。不要在页面上做完整性勾选（产品规定不做）。

## 8. 统计与大屏

- **运行统计**的演示数字来自样本表，汇报时要说是样本。
- **大屏**给指挥看，数据和台账同一套。

## 9. `reviewer1` 能做什么

- 进工作台、融合感知、飞行计划、告警、处置与处罚等已授权菜单。
- 批准他人的处置、复核他人的处罚。
- 不要批自己申请的处置，不要复核自己承办的案件。
- 不要进用户/角色/审计（没有菜单）。
- 设备管理可能只有只读或没有写权限：不要改台账，处置执行若提示没有设备权限，交给 `admin1`。
