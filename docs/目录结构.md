# 目录结构

本文件描述 2026-09-16 的仓库边界，不代表所有能力已通过运行验收。当前流程见 [flow-map.md](flow-map.md)，产品与维护约束见[根 AGENTS.md](../AGENTS.md)。本仓库只维护业务前台；唯一后端和管理端在同级 `../houtaiguanli`。历史后端开发基线、协作计划和阶段报告保留追溯用途，不作为在本仓重建后端的依据。

```
├── dongying-vue/           前端
│   ├── public/             运行时静态资源
│   │   └── assets/
│   │       ├── img/        品牌、主题插画、大屏切图
│   │       └── js/         legacy IIFE（经典 script 顺序加载）
│   ├── src/
│   │   ├── assets/css/     全局样式（入口 index.css）
│   │   ├── components/     跨页 Vue 组件（form/ 为公共表单件）
│   │   ├── config/         导航/路由/主题静态表
│   │   ├── hooks/          跨模块 composable
│   │   ├── layout/         应用壳层
│   │   ├── pages/          路由页面与迁移注册表
│   │   ├── router/         Vue Router
│   │   ├── services/       API、权限、数据装配和地图共享服务
│   │   ├── stores/         Pinia
│   │   ├── ui/             Naive UI 适配（toast/modal/theme/表单）
│   │   └── main.js         入口：先加载 CSS，再挂 Vue
│   ├── tools/              扫描、证伪、母本对照
│   ├── AGENTS.md           前端开发规则
│   ├── index.html          经典脚本加载顺序 + Vue 入口
│   └── vite.config.js
├── map-data/               当前 PMTiles 地图包及配套资源，独立于 dist
├── deploy/                 前端静态站点及地图服务配置示例
├── docs/                   项目文档
│   ├── 验收材料/           P0 交付：验收用例、协议缺口、口径、操作说明、联调日志模板
│   ├── 后端开发基线.md     范围、能力、来源、顺序与待确认资料
│   ├── 数据库设计文档.md   现有表、拟建字段关系、约束与分期迁移
│   ├── 协作开发环境.md     历史环境方案；当前 Git 规则见根 AGENTS.md
│   └── 后端双人协作开发计划.md 双人分工、12 周顺序和验收门禁
├── AGENTS.md               仓库级说明
└── README.md
```

同级后台仓库（不在本仓库新增副本）：

```text
../houtaiguanli/
├── server/                 Spring Boot、数据库迁移与后端测试
├── ruoyi-ui/               运维与系统管理端
├── scripts/                后台启动脚本
├── docs/                   后台契约、迁移及部署记录
└── AGENTS.md
```

前台业务入口由 `src/config/navModel.js`、`src/router/` 和 `src/pages/registry.js` 共同确定。六个旧管理地址显示迁移提示；磁盘中的残留旧组件不代表有效入口。`public/assets/js/` 仅保留 `ui.js`、`charts.js`、`geo.js`、`map.js`、`video.js` 和 vendor，`mock.js` 与旧 `pages/` 已删除。

## dongying-vue/src/assets/css/

```
dongying-vue/src/assets/css/
├── index.css               入口，@import 顺序即层叠顺序
├── tokens.css              主题 token 唯一真源
├── reset.css               全局复位、滚动条
├── visual-2026.css         2026 视觉覆盖层
├── themes.css              body[data-theme] 模块插画
├── layout/                 壳层：顶栏/导航/面包屑/大屏模式
├── mixins/                 通用布局工具类
├── components/             跨页组件类
└── pages/                  单页样式（飞行计划、合法性、大屏等）
```

改 token 只改 `tokens.css`。改顶栏/导航/面板时同时看 `layout/`、`components/` 和 `visual-2026.css`。

## 同步边界

- `dongying-vue/public/assets/js/**` 与 `dongying-vue/public/assets/img/**` 仅在有明确同步任务和有效母本时逐项对照，禁止以旧版整目录覆盖当前业务或恢复删除项。
- 样式以 `dongying-vue/src/assets/css/` 为准，不再要求与母本 `app.css` 逐字节一致。
- 产品表单只使用 `dongying-vue/src/components/form/`（`UField` / `UFieldGrid` / `UFormFooter`）。新弹窗走 `openFormModal()`；存量 innerHTML 控件由 `dongying-vue/src/ui/legacyControls.js` 升级，不要再扩大这条兼容路径。

## 后端目录与文档维护

- 后端实现、测试、迁移与部署遵守[后台仓库规则](../../houtaiguanli/AGENTS.md)及[后端规则](../../houtaiguanli/server/AGENTS.md)，启动入口见[后台 README](../../houtaiguanli/README.md)。不在本仓库创建 `server/` 或另一套数据库迁移。
- 后台迁移状态见[新后端迁移记录](../../houtaiguanli/docs/新后端迁移记录.md)。本仓历史文档里的 `server/` 路径按原日期解释，实际维护位置是同级后台；不能机械照抄旧迁移编号。
- 公共契约变化同时核对业务前台与管理端消费者，文档分别在其所属仓库维护。
- [数据库设计文档](数据库设计文档.md)描述拟建表和现有表的增量设计，不代表迁移目录中已存在对应 SQL；实际结构仍以版本化迁移及运行验证为准。
