# 飞行计划气象风险（2026-09-14）

> 2026-09-15 仓库归属：本文后端 `server/` 路径指同级 `../houtaiguanli/server/`；历史验证记录保留原日期。迁入后台后的迁移版本与验证结果以后台 `docs/新后端迁移记录.md` 为准。

飞行计划同时包含空中异物风险与气象风险。气象风险可在起飞前影响计划，不依赖目标、轨迹或异物空间事实，也不等同实际飞行合法性判定。

## 页面体现

- 飞行计划详情“本计划的风险记录”按计划关联展示全部风险，摘要区分异物/气象数量，气象行显示“大风预警”“雷雨预警”“低能见度预警”。沿用原来近 7 天、最多 50 条的展示范围，摘要中的分类数为当前显示条数，不冒充全量。
- “全部风险事件”首屏筛选直接提供风险类型；顶部统计分别列出气象风险与异物风险，均读取服务端 total。原来空间安全汇总的涉及航线指标明确改名“异物涉及航线”。
- 筛选气象风险时清除并忽略目标类型筛选，避免没有关联目标的天气风险被排除。
- 气象详情隐藏目标高度、高度关系和光电跟踪，展示来源、预警原因、记录时间、关联计划；地图叠加已保存的气象范围和关联航线；未提供范围时不伪造区域。
- 风险仍走既有待核验 → 待通知 → 通知/回执链路。已完成或取消计划不新增起飞前风险区，历史仍可在全部风险事件查看，不删除记录。

## 演示数据及边界

当前没有真实气象预报/实况适配器，也没有经确认的风速、能见度或航空器运行阈值。本次使用独立 `WEATHER-DEMO` 演示源，经 RiskIngestionService 入库，不把设备 MQTT 协议包装成气象来源。

LocalWeatherRiskSeeder 仅在 local、非 production 且开发种子开启时运行。三个样例关联计划-0911-101（大风）、计划-0911-102（雷雨）、计划-0911-103（低能见度）；均为 mock，文字明确标识模拟预警、适用时段及预设等级，不添加虚假目标/轨迹/高度。每日稳定来源编号保持幂等，重启不重置已核验、已通知的风险。

后续接真实数据需明确来源、发布/有效时段、影响区域和运行限制。当前天气页面的装饰性天气值不能直接拿来自动生成飞行风险。本轮没有实现生产天气风险自动计算。

## 气象风险地图补充（2026-09-14）

用户已确认参考案例后的地图方案。入口为“飞行计划 → 全部风险事件 → 气象风险”，也可从计划详情“查看风险详情”进入：

- 点击记录后同时定位航线和气象多边形，雷雨用玫红、大风用琥珀、低能见度用紫色半透明区域。区域标题和折叠图例标明模拟来源。
- 大风区域箭头指向风吹去的方向，预警详情显示模拟风速 12 米/秒、风来向 315°；低能见度样例为 800 米。数值不作为生产运行阈值。
- 航线平面落入区域的部分加紫色外圈，保留原有航线绘制；只表达几何交集，不声称已经判断时间、高度与实际飞行影响。
- 点击区域或“预警详情”展开来源、发布时间、有效时段、气象数值；地图图例改为右下角小型可折叠毛玻璃卡，气象记录不再重复显示原异物圆点图例。支持单独隐藏区域。
- 未来时段、有效时段、过期记录分别显示“尚未到预警时段 / 处于预警时段 / 已过有效期 · 历史范围”。历史范围可查看，已完成/取消计划仍走原风险历史入口，不改业务状态或核验/通知链路。
- 切换记录清空旧范围，请求失败可重试；天气范围加载失败不影响已取得的航线显示。只有范围、无航线权限时仍可在风险读取权限下查看风险范围。

### 接口与存储

`GET /api/v1/risks/{riskId}/weather-fact`：先执行 risk:read 及原风险对象范围鉴权，无权限/不可见沿用现有 403/404 行为。无事实或非气象事件返回 ok=true、data 缺省；列表/统计不加载气象范围，不新增轮询请求。

返回字段：`polygon` 为 WGS-84 经纬度闭合外环；`published_at / valid_from / valid_to` 为 epoch 毫秒；可选 `wind_speed_mps`（米/秒）、`wind_from_degrees`（0–360°，不含 360，来向）、`visibility_m`（米）；`source_mode` 来自风险主记录。当前没有高度范围。

新增 Flyway `V202609140003__weather_risk_map.sql`，使用独立 weather_risk_fact 表存范围和时段快照。坐标以 TEXT 保存，JSON 序列化在 Java 完成。已有迁移不变。

LocalWeatherRiskSeeder 为当天三个已有模拟风险补充固定范围，范围由模拟器明确给出，不由前端沿航线画圈。有效时段取风险原有说明，避免演示计划在重启时移动时间后改写旧风险事实；已有范围和核验/通知记录不覆盖。真实气象适配器未接入。

## ForeFlight 气象质感修正（2026-09-14，用户 07:16 反馈）

视觉基准为用户指定的 [ForeFlight Weather](https://foreflight.com/products/foreflight-mobile/weather/) 中 Dynamic Winds and Temperatures 与 NEXRAD Radar。用户截图作为当前差异依据：原版本是单色多边形、粗虚线、大箭头和中央黑底标题，缺少气象色带与流场质感。本轮只修正飞行风险地图的天气表现，不改变导航、后台接口、天气记录或业务状态。

- 专属 WEATHER-DEMO / mock 三类气象风险采用本地确定性模拟纹理：大风为蓝青绿黄的连续色带及细密白色流线，雷雨为绿黄橙红的不规则色斑，低能见度为柔和灰紫色层。没有复制 ForeFlight 图片、商标或产品截图作为界面资产。
- 所有纹理限于接口给出的范围内，边缘渐隐；不扩大真实影响范围、不追加强度测量值、不参与风险评估。色标明确写“模拟分布”，仅表示示意强弱，不能读作某一点实测风速或回波强度。非专属模拟来源保持已有区域事实展示，不回退为模拟纹理。
- 默认隐藏粗边界，图例提供“显示预警边界”；标题移到地图角落小卡，不遮住航线。关联航线与既有紫色区域内航段外圈保留，外圈适当减弱。
- 风流线采用服务器保存的风来向，画出吹去方向；动画复用现有 MapView 循环，纹理一次生成并缓存，不添加第二个活动地图或动画循环。系统减少动态效果设置下静止显示。
- 地图底部新增小色标，原可折叠毛玻璃图例、图层开关、时段提示和详情保留。切换事件恢复边界默认隐藏。

代码：`weatherMap.js` 的 weatherPolygon 增加退化区域检查，simulatedTexture / drawWindParticles / drawWeatherArea 负责模拟纹理与流线；`WeatherMapInfo.vue` 的 gradient 及模板样式负责色标、边界开关和标题位置；`FlightsPage.vue` 的 simulatedWeather / weatherKind / resetRiskWeather / renderRiskMap 负责来源门禁、类型映射、切换清理和绘制参数。
