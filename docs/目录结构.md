# 目录结构

本文件描述当前可运行代码的目录约定。产品路线图见 `docs/整体改造方案.md`。

```
├── dongying-vue/           前端
│   ├── public/             运行时静态资源
│   │   └── assets/
│   │       ├── img/        品牌、主题插画、大屏切图
│   │       └── js/         legacy IIFE（经典 script 顺序加载）
│   ├── src/
│   │   ├── assets/css/     全局样式（入口 index.css）
│   │   ├── components/     跨页 Vue 组件（form/ 为公共表单件）
│   │   ├── config/         导航/路由/主题静态表
│   │   ├── hooks/          跨模块 composable
│   │   ├── layout/         应用壳层
│   │   ├── pages/          路由页面与迁移注册表
│   │   ├── router/         Vue Router
│   │   ├── services/       共享服务（权限、天气、工作台入口）
│   │   ├── stores/         Pinia
│   │   ├── ui/             Naive UI 适配（toast/modal/theme/表单）
│   │   └── main.js         入口：先加载 CSS，再挂 Vue
│   ├── tools/              扫描、证伪、母本对照
│   ├── AGENTS.md           前端开发规则
│   ├── index.html          经典脚本加载顺序 + Vue 入口
│   └── vite.config.js
├── server/                 后端骨架（Spring Boot）
├── deploy/                 Compose 与 Nginx 示例
├── docs/                   项目文档
├── AGENTS.md               仓库级说明
└── README.md
```

## dongying-vue/src/assets/css/

```
dongying-vue/src/assets/css/
├── index.css               入口，@import 顺序即层叠顺序
├── tokens.css              主题 token 唯一真源
├── reset.css               全局复位、滚动条
├── visual-2026.css         2026 视觉覆盖层
├── themes.css              body[data-theme] 模块插画
├── layout/                 壳层：顶栏/导航/面包屑/大屏模式
├── mixins/                 通用布局工具类
├── components/             跨页组件类
└── pages/                  单页样式（工作台、用户、合法性、大屏等）
```

改 token 只改 `tokens.css`。改顶栏/导航/面板时同时看 `layout/`、`components/` 和 `visual-2026.css`。

## 同步边界

- `dongying-vue/public/assets/js/**` 与 `dongying-vue/public/assets/img/**` 仍可按 `dongying-demo` 母本对照。
- 样式以 `dongying-vue/src/assets/css/` 为准，不再要求与母本 `app.css` 逐字节一致。
- 产品表单只使用 `dongying-vue/src/components/form/`（`UField` / `UFieldGrid` / `UFormFooter`）。新弹窗走 `openFormModal()`；存量 innerHTML 控件由 `dongying-vue/src/ui/legacyControls.js` 升级，不要再扩大这条兼容路径。
