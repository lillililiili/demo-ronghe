# 风险通知状态口径

2026-09-10 用户确认：通知提交或发送成功后为“已通知”，取得确认回执后为“已回执”。本说明替代此前收到回执才进入已通知的规则；此前测试报告保留为历史记录。

| 状态 | 进入条件 |
| --- | --- |
| 待核验 PENDING_VERIFICATION | 风险创建 |
| 待通知 PENDING_NOTIFICATION | 人工核验属实 |
| 已通知 NOTIFIED | 通知提交事务成功；投递情况另行显示 |
| 已回执 ACKNOWLEDGED | 渠道返回有效送达及确认回执 |
| 已排除 EXCLUDED | 人工核验排除 |

提交失败、版本冲突、事务回滚不会推进状态。提交成功但渠道未接通或投递失败时，风险仍为已通知，页面单独显示投递状态及阻断原因。客户端不能自行填写可信回执。实时风险不因模拟渠道回执进入已回执。

即时返回有效回执时，同一事务记录已通知和已回执两个阶段，每阶段递增版本并写审计；刷新直接看到最终已回执。其他接收方的后续通知不回退状态。材料快照保持各次提交前的风险版本。

入口：飞行计划的风险列表、详情及状态筛选；工作台风险状态和四步流程；交接页面的独立投递、回执记录。

新增迁移 V202609100002：扩充状态约束；已有通知交接的待通知风险补为已通知；历史 mock/replay 风险存在有效送达及确认记录时补为已回执。实时记录不推测渠道真实性。核验历史、原始消息和交接材料保持不变。

当前确认来自已接入的通知渠道返回值。本地 Mock 对风险通知只模拟已送达、等待回执，不在提交当时假装上级已确认；真实外部异步回执入口仍需随实际渠道接入，不能把定时等待当成收到回执。已回执样例由种子历史记录展示。
