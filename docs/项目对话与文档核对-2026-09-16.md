## 范围与使用方式

本轮读取了可访问的 39 个项目相关任务、335 条回合记录，包含 8 个已归档任务及追溯到的“排查提交时新建分支”任务，已翻完这些任务返回的历史分页。任务清单见文末。部分历史回合已压缩，仅有摘要或缺少正文；未重新解读原始录音、截图和附件，也不声称覆盖所有账号、设备或未列出的对话。其他项目的对话不写入本项目规范。

同时检索项目 Markdown 文件，重点核对两级 AGENTS、两级 README、目录说明、业务流程和近期专题文档，并与导航注册、实际文件、地图加载及短信展示代码对照。采用“用户明确决定 → 后续修订 → 当前源码/验证证据”的核对顺序；助手曾提出的建议不自动成为用户要求，旧测试结论不当作本次验收。

两级 AGENTS 保存稳定约束，README 说明入口和现状，专题文档保存接口、阶段及待验证问题。此次是文档维护，不是功能修复或部署。
