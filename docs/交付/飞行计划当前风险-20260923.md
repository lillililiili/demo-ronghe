# 飞行计划当前风险 · 2026-09-23

## 实现边界

新增 `GET /api/v1/risks/current`，支持 `plan_id`、`page`、`size`、`exclude_demo_samples`。当前气象依据在有效时段内为 CURRENT；尚未到有效时段不计入，过期、依据异常、缺少持续依据为 UNKNOWN。其他类型目前没有可靠的持续／解除契约，如实显示状态待确认。已通知、已签收不代表解除。没有新增人工必经步骤，也没有修改通知、反制权限或历史状态。
