## A. 三条闭环

### A1 黑飞 / 无人机事件（发现 → 核实 → 处置 → 证据）

| | |
| --- | --- |
| **前置** | `local` 种子已起来。告警页有「已核实，待处置」事件（如演示「告警-0907-013」）或先用 `admin1` 把一条待核实标属实。凌云处置准备 `S85F1`（干扰/反制）且 MQTT 在线并有回执脚本；或四通道用 `CM4-LOCAL` 且监测显示在线。`reviewer1` 已种。 |
| **步骤** | 1. `admin1` 打开告警事件，点该行，确认详情为已核实。2. 点「发起联动反制」，通道选凌云 B 或四通道，填对应设备 ID，事由 ≥2 字，提交。3. **退出**，用 `reviewer1` 登录处置与处罚页（或告警详情若有审批入口），批准（批准人不能是申请人）。4. 仍用有 `disposal:execute` 且有 `devices` 操作权的账号执行。5. 等回执或打开授权详情看状态。6. 证据管理或详情证据链能看到与授权/命令相关的环节。 |
| **预期** | 申请 `REQUESTED`；另一人批准后 `APPROVED` 且有时限。执行后 `EXECUTING`，回执成功 `COMPLETED`。凌云成功 `PROTOCOL_B_OK`；四通道成功 `COUNTERMEASURE_SET_OK`，`simulated=true` 时页面/回执不得写成现场已打击。刷新后授权仍在。 |
| **数据不足时** | 未核实：409「该动作要求事件已核实为属实」。无设备：400 须填设备。凌云未绑定：409 `DEVICE_NOT_BOUND`，授权仍 `APPROVED`，流程条「设备未登记凌云连接」。离线：`DEVICE_OFFLINE`。四通道配雷达：`DEVICE_CAPABILITY`「所选设备不能走该通道自动执行」。诱骗/驱离选四通道：400，不发射。自己批自己：409 `TWO_PERSON_RULE`。不要出现成功 Toast 却无授权行。 |

停止：授权 `APPROVED`/`EXECUTING` 时可停。凌云急停不可用 → 「授权已撤销；设备急停未执行（协议未提供）」。四通道成功全关 → 「授权已撤销；已向四通道网络控制器下发全关，回执以设备为准」。**不要把全关叫成急停。**

### A2 报备飞行异常（偏离 → 通知 → 不编超高）

| | |
| --- | --- |
| **前置** | `admin1` 能进飞行计划。种子里有计划或对照；规则引擎在 local 是否打开以实际配置为准（缺省生产关）。 |
| **步骤** | 1. 打开飞行计划，看今日/执行中等 KPI（服务端 total）。2. 打开一条计划，看对照：计划匹配、高度带、轨迹。3. 若有风险/偏离，用「通知上级」（工作台或计划页已有交接则按钮禁用）。4. 合法性研判页打开同一对象，看结论词。 |
| **预期** | KPI 为数字或「—」+ 说明，不出现假 0 冒充「没有计划」。偏离显示「部分匹配」或规则不通过，且原因可读。重复通知禁用，title 说明已提交。 |
| **数据不足时** | 无研判：`NO_EVALUATION` / 「尚无引擎研判」，不要判非法。高度基准未确认：不出现「超高成立」类确定结论；高度带可为「不可判定」。无可信几何：地图「可信输入几何尚未接入」。导出按钮「导出（尚未接入）」。 |

### A3 设备异常（告警 → 工单动作 → 恢复校验）

| | |
| --- | --- |
| **前置** | 设备实时监测或工作台有设备异常单。`test` 台账 `DEV-MOCK-*` 不在 `local` 种子里；local 用 MQTT/四通道设备。Mock 适配器重启仅 `source_mode=mock`。 |
| **步骤** | 1. 打开设备实时监测或工作台设备事项。2. 对异常单点重启（若 `allowed_actions` 含重启）。3. 等命令 `SUCCEEDED` 后做恢复校验。4. 对 T02 或 `CM4-LOCAL` 尝试重启，确认被拒。 |
| **预期** | 声明了重启的协议：命令排队并有回执；成功只到待验证，不把「指令成功」写成「异常已关闭」。T02 / 四通道：409 `DEVICE_NOT_OPERABLE`，文案含未声明重启。工作台若写「到设备实时监测页处置」，应能跳到监测页。 |
| **数据不足时** | 离线/停用不能重启。live 雷达重启失败不是「现场已验收失败」，只是协议未开放重启。 |

## B. 按页面补点

权限不够时应看到无权限说明，不要白屏。`reviewer1` 菜单少于 `admin1`（无系统管理、无完整运维写）。刷新后会话仍在则停在本页。

### B1 我的工作台 `#/workbench`

| 前置 | `admin1` 登录 |
| --- | --- |
| 步骤 | 打开工作台，看事项列表、下一步、事项位置地图 |
| 预期 | 有事项则「下一步」为中文动作；位置有坐标才打点 |
| 数据不足时 | 无坐标写明原因，不打 (0,0)。设备重启未在工作台接通时说明去监测页。已有未了结反制时「发起联动反制」禁用 |

| 前置 | 融合领取过回放或有目标 |
| --- | --- |
| 步骤 | 看目标列表/地图；悬停气泡；无位置 AOA 看方位线；点光电跟踪（有位置时） |
| 预期 | 目标编号是业务号不是裸 UUID。有风险/违规/处置摘要才显示那一行 |

## C. 明确不算通过的项

不要因为下列失败而开本平台缺陷（除非页面谎称已成功）：

- 连 `192.168.0.7` 或现场雷达网段
- 急停成功
- 协议 C 云台/home
- T02 启停
- 控制回执出现在融合目标 inbox
- 空库未配 `local` 就要求有演示数据
