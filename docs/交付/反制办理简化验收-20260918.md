# 反制办理简化验收（2026-09-18）

## 页面与操作

- 告警事件 → 反制办理：默认进入待我处理，显示当前账号可审批、可执行的设备授权。自己的申请不进入自己的审批待办。
- 全部记录保留状态筛选、分页、执行监测、停止入口及历史。每条记录突出一个当前办理动作；查看、刷新、打开停止区均不下发指令。
- 查看详情后在同一工作区呈现关联对象、动作、状态、设备停止入口和授权事实；返回列表恢复列表，避免小屏同时挤放两块内容。
- 关联业务编号从对应事件/目标读取；失败明确提示，保留授权记录辨识信息。完整待办读取失败不显示为空待办。
- 前台申请和直接反制仅可选设备通道，设备必选；移除人工执行和人工结果登记表单。旧人工执行记录仅供查阅，不修改历史结果。急停后现场停机核查继续保留。
