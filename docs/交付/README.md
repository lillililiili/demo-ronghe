# 交付文档（协作者 B 线）

给甲方和联调现场看的六份文档。正文说人话，不出现代码名、英文码和内部编号；每一句关于系统行为的话在 `内部依据/` 下的同名文件里有出处（内部核对用，交付时不随正文发出）。

| 文档 | 给谁看 | 用途 |
| --- | --- | --- |
| [甲方验收用例](甲方验收用例.md) | 甲方验收人员 | 按会议纪要的页面和三条闭环逐条验；写清前置数据、步骤、预期，以及数据不足时页面应显示什么 |
| [操作说明](操作说明.md) | 值班员 | 按班次的操作路径：接班、看态势、处理告警、申请与审批处置、交接与处罚、交班 |
| [口径说明书](口径说明书.md) | 验收人员、值班员 | 页面上"尚未接入""不可判定""暂不可用"分别是什么意思、谁能消掉；数据不足时说判不了，不编结论 |
| [协议缺口矩阵](协议缺口矩阵.md) | 联调双方、客户 | 逐设备逐能力：协议有没有定义、我们实现没有、没实现时页面显示什么、联调要验什么；口径类待确认项单列 |
| [联调日志模板](联调日志模板.md) | 联调现场工程师 | 每一路一张记录表，附取报文的方法 |
| [安装与升级记录](安装与升级记录.md) | 部署与运维 | 空库安装与旧库升级各一次完整记录，以及两条路径结果一致的核对 |

更新规则：改正文里的任何一句系统行为，同步改 `内部依据/` 里引用该原句的那一条。
