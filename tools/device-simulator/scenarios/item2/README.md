# 第二条模拟场景

本目录包含 14 个地图场景，以及 `notification-configs/` 下 6 个既有实时收发配置。

使用现有模拟器“场景工具”导入地图 JSON。业务组使用标准化观测；`06-mqtt-height-unknown` 与 `07-mqtt-no-sn` 使用协议 A。两组结果分别取证，不能用标准化观测补出的高度或 SN 证明协议 A 已具备该信息。

启动前核对北京时间的计划和空域窗口；`08-device-fault`、`09-device-offline` 的独立运维检查计划默认 23:00—23:59，请调整为当前时间之后，走现有“起飞前·周边设备检查”入口。不要修改业务页面的适用条件。重复的空域定义完全一致才复用，内容变化仍按平台版本规则处理。

通知配置通过现有收发模式设置或 `/api/realtime/config` 使用，不是地图 JSON。先停止全部收发再切换。接收端只回传平台真实出站请求，不主动制造成功；资料不足仍由平台阻断。播放历时不改变短信 3 秒、电话播放完成后 10 秒的观察时长。

场景不包含密码、真实飞手核验、审批人或预设业务结论。普通反制需要另一授权账号审批；协议 A 恢复在线不足以证明健康 GOOD。完整操作步骤、测试数量及未完成项目见管理仓库：
