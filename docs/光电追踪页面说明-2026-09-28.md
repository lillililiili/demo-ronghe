# 光电追踪页面说明

告警详情、合法性研判详情与非气象风险详情使用 `TargetTrackingPanel`，共用目标级光电任务及后端状态。告警页原“人工补跟踪”独立区已移除；合法性页在原视频位置提供同一套操作；风险页通过 `RiskOpticalPanel` 保留适用范围。

## 自动与人工分工

- 告警待核实、已确认后的有效观察需求，当前违法或异常研判，以及明确需要观察的非气象风险由后端统一评估。
- 不因为打开页面、切换记录或刷新而下发指令；后台自动开关关闭时明确显示未启用。
- 无任务且后端允许时可“人工补跟踪”；明确失败且允许安全重试时可“重试跟踪”。位置过期、没有设备等情况不通过按钮绕过。
- “暂停并结束”作用于同一个目标，告警、研判和风险三个入口同步。暂停持久保存；“恢复自动追踪”只解除目标暂停，不开启系统总开关。
- 缺少报备计划、身份、规则参数、时间或高度基准不等于缺少视频，不因此自动追踪。当前未提供明确视觉补证协议的不可判定记录，保留人工补看及原因提示。
- 气象风险沿用原页面，不出现目标追踪；异物风险缺少目标时明确说明。
- 气球等未接入追踪的类别：没有进行中任务时，显示“暂未接入气球自动追踪，暂无该目标的跟踪画面。”（其他类别用通用提示），不显示暂停/恢复按钮；位置已过期或旧暂停标记不掩盖类别未接入原因。已有任务或停止结果未知时仍保留后端允许的停止操作，页面始终消费同一状态接口。

## 读取与操作契约

`GET /api/v1/targets/{id}/eo-tracking-status` 返回目标 ID、状态、说明、自动开关/暂停、需求原因、任务来源和 `allowed_actions`。前端不自行计算追踪资格。响应缺失或目标不一致时显示读取失败并隐藏动作。

`POST /api/v1/targets/{id}/eo-tracking-tasks` 复用人工发起接口；`POST /api/v1/targets/{id}/eo-tracking-pause`、`eo-tracking-resume` 接收幂等键。每次人工操作后重新读取状态，提交返回并不等于设备已执行。

跟踪与视频是两项事实。视频默认收起（2026-10-10 用户确认），点击查看后展开；切换事项或重新进入页面恢复收起。手动收起停止播放器，不结束后台任务。切换目标、身份、页签或卸载时清除请求与轮询；旧响应不能覆盖新对象。无权限、读取失败和没有任务分别展示。

## 验证记录

本次公共面板通过 Vite 构建、源码扫描、API 模块语法检查及项目外 Vue 挂载测试。挂载测试验证只读 GET、按钮资格、暂停/恢复回读、读取失败、目标切换的旧响应隔离，无 pageerror。隔离后端和 PostgreSQL 的真实浏览器联调已验证告警页暂停、合法性页同目标同步与恢复、收起视频不结束任务、风险页暂停及位置过期阻断；未发现浏览器控制台错误。页面布局与原视频位置保持一致。本地测试不证明实际光电锁定或现场视频能力。
