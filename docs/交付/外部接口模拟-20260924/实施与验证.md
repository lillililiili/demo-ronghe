## 业务入口与操作（本轮初版联调时）

本机启动 `python3 tools/device-simulator/server.py --port 8766 --database houtaiguanli` 后，打开 `http://127.0.0.1:8766/external.html`。模拟器顶栏可在“信号地图”和“外部接口模拟”之间切换。外部接口页独立登录现有系统 API，操作输入与回执不依赖 MQTT 连接；需要产生新的风险或告警来源时，仍按原信号模拟与平台业务流程运行。登录凭据只存于本机 Python 服务内存，服务重启需重新登录。

| 页面类别 | 当前本机操作 | 系统中的结果与边界 |
| --- | --- | --- |
| 飞行计划输入 `FLIGHT_PLAN` | 选择可见的模拟航线版本，生成或编辑带 `message_id` 的 JSON 后提交。 | 后端校验航线归属、范围和有效期，新增 `source_mode=mock` 的待执行计划；受理不等于飞行获准、已起飞或研判合法。相同编号且内容相同返回原记录，内容不同返回冲突。 |
| 气象预报输入 `WEATHER_FORECAST` | 选择可见的模拟计划，编辑发布及预报时段后提交。 | 系统持久保存该计划的模拟预报，读取时返回 `READY` 或 `STALE`。历史计划可得到过期预报；提交本身不自动生成风险。 |
| 风险通知接收 `RISK_NOTICE` | 对系统已有且可见的 mock/replay 风险启用最长 20 分钟的模拟接收，等原风险核实和“通知上级”流程发出消息，再对该消息回送送达、签收、失败或超时。 | 绑定本身不发送通知。送达与签收分别存储；超时是结果未知，不能写成确定失败；签收不等于风险解除。 |
| 处罚通知接收 `UAV_PUNISHMENT` | 对系统已有且可见的 mock/replay 无人机事件绑定模拟接收，等原处罚交接与通知流程发出消息后回送结果。 | 处罚材料仍按原权限与状态形成并冻结，回执关联同一交接投递；签收不等于处罚办结。 |

页面每 5 秒在可见且已登录时只读刷新，记录可展开查看原始报文与系统结果。计划与交接记录分别提供业务页深链。会话失效会立即清除连接和旧列表，编辑中的报文草稿保留。页面显示 `unavailable_sections` 中逐类权限缺口；当前消息版本冲突需刷新后按最新事实处理。没有投递关联标记的发出消息显示 `UNKNOWN` 和核对说明，页面不提供回执按钮。所有模拟回执均标注模拟，不代表真实短信、电话、第三方接口或现场设备回执。
