# 空域处置预案接入

用户确认补齐后台配置、发布、关联和前台查看。本次保留原空域列表、地图、详情结构与权限范围。

业务前台：空域管理选择空域后，“处置预案”直接读取服务端当前关联，显示名称、具体版本、来源、发布人、有效期、关联依据、更新时间和适用性；展开可读完整内容及历史。未关联、服务失败、无权限、待生效、过期、停用和空域未生效分别呈现。切换空域立即清空旧状态，丢弃迟到响应。

后台：系统管理新增“处置预案”，通过草稿保存、版本发布、空域关联形成真实持久化链路。发布后内容不可覆盖，新版本不会自动替换旧空域关联；替换/解除有时间、人员、原因和审计。

本次预案是处置说明配置，发布及关联不会触发通知或下发设备指令。自动短信和电话策略、反制授权与真实执行回执维持既有契约；未接入预案驱动的事件执行及执行快照。

详细契约与数据库迁移见[后台处置预案接口](../../houtaiguanli/docs/处置预案接口-2026-09-17.md)。旧文档中“配置、发布、关联和查询尚待接入”的部分已由本次实现替代，事件执行快照仍未实现。

代码：AirspaceResponsePlan.vue 负责查询状态、详情及历史；airspaceApi.responsePlan() 访问 GET /airspaces/{id}/response-plan；AirspacePage.vue 将原占位替换为组件。样式使用既有 tokens，无新依赖或导航重构。
